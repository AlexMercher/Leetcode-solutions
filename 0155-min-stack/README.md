## Explanation

Suppose we push:

-2
0
-3

The stacks become:

st:       [-2,  0, -3]
mn:       [-2, -2, -3]

Notice mn means:

mn.top() = minimum of everything currently in st

So:

getMin()

is simply:

return mn.top();

After:

pop();   // removes -3

we get:

st: [-2, 0]
mn: [-2, -2]

Therefore:

getMin() → -2

Every operation only does a constant number of stack operations:

push    → O(1)
pop     → O(1)
top     → O(1)
getMin  → O(1)

The key idea is:

Store the minimum corresponding to every stack position, so you never have to search for it.
