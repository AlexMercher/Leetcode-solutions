## Explanation

Why abs(st.top() - c) == 32?

In ASCII, lowercase and uppercase versions of the same letter differ by 32.

For example:

'a' = 97
'A' = 65

97 - 65 = 32

Similarly:

'b' = 98
'B' = 66

98 - 66 = 32

So:

abs(st.top() - c) == 32

means:

They are the same alphabet letter, but one is lowercase and the other is uppercase.
