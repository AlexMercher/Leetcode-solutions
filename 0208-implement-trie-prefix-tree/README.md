## Explanation

insert("apple"):
root
 ↓
 a → p → p → l → e
                 ↑
              isEnd=true

search("app"):
a → p → p

Path exists, but:
isEnd = false

so return false.
startsWith("app") only asks:
Can I follow the path a → p → p?

It does not care whether a word ends there, so it returns true.
Complexity
For a word of length L:
insert     O(L)
search     O(L)
startsWith O(L)

The key mental model:
Trie = tree where each edge represents a character, and a path from root represents a string.

children tells you where the prefix can continue, and isEnd tells you whether a complete word ends here.
