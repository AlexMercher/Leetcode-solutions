## Explanation

Initially:
- dp[0] = 0
- Every other spending amount is unreachable (-1).
When processing item type i, we have two choices:
- Buy zero copies of it, and keep our previous result.
- Buy k >= 1 copies of it. We pay k * price and gain k + bonus[i] copies.
The important restriction is that we must start this transition from the DP of previously processed item types, not from a state that already contains this item type's bonus.

2. Optimize the transition
A straightforward transition would try every possible k, which could be too slow.

Instead, group spending amounts by their remainder modulo price.

Let:
- (p) = price of the current item.
- (c=r+qp), where (r) is the remainder and (q) is the quotient.
- (k) = number of copies bought of this item.
If we buy k copies, our previous spending amount is:
c-kp=r+(q-k)p
