## My Notes

##The rule to remember

There are two common binary search templates.

Exact search

Searching for an exact value:

if (nums[mid] == target)
    return mid;

You often do:

high = mid - 1;

or

low = mid + 1;
Boundary search (this problem)

Searching for:

first true
first bad version
lower bound
insertion position

When mid is a valid candidate:

if (condition(mid))
    high = mid;

When mid is definitely not the answer:

else
    low = mid + 1;

Notice that you never discard mid when it could still be the boundary.
