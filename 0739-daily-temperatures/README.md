## Explanation

Suppose we have:

73, 74, 75

After seeing 73:

stack = [index 0]

See 74:

74 > 73

So 74 is the warmer day for index 0.

ans[0] = 1

Then 74 itself waits in the stack for something warmer.

See 75:

75 > 74

so:

ans[1] = 1

The stack contains unresolved days.

That's the pattern:

Current temperature resolves all previous smaller temperatures sitting on top of the stack.

Your brute-force logic is conceptually correct; the two bugs are right = left and +1. The stack version is the optimization from O(n²) to O(n).
