## Explanation

Example:

logs = ["d1/","d2/","../","d21/","./"]

Start:

depth = 0
main/

"d1/":

main/d1/
depth = 1

"d2/":

main/d1/d2/
depth = 2

"../":

main/d1/
depth = 1

"d21/":

main/d1/d21/
depth = 2

"./":

same folder
depth = 2

So:

answer = 2

It takes two "../" operations to get back to the main folder.

Why don't we need to know the folder names?

Because the question only asks:

How many operations are needed to get back to the main folder?

We don't care whether the path is:

main/a/b/c

or:

main/x/y/z

Both have:

depth = 3

and therefore need exactly 3 "../" operations.

Important edge case
logs = ["d1/","../","../","../"]

Process:

d1/  → depth = 1
../  → depth = 0
../  → depth = 0
../  → depth = 0

We never go below 0 because the main folder has no parent.

So answer:

0
Pattern

This is a useful recognition:

child folder → +1
../          → -1
./           →  0

So the entire problem reduces to: A stack.
