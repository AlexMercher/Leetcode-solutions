## Explanation

Take:

nums = [1, 2, 3]
k = 3

At 1:

subarrays ending here:
[1] -> 1
dp = {1:1}

At 2:

[2]     -> 2
[1,2]   -> 1*2 % 3 = 2

dp = {2:2}

At 3:

[3]     -> 0
[2,3]   -> 2*0 % 3 = 0
[1,2,3] -> 2*0 % 3 = 0

dp = {0:3}

So we're effectively counting every non-empty contiguous subarray exactly once.

Complexity

For every element we scan the k possible remainders:
O(nk) Time and O(k) extra space.

Use long long for the counts because the number of subarrays can be n(n+1)/2; thus exceeding the total int capacity.
