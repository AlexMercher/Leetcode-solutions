## Explanation

# LeetCode 3016 – Minimum Number of Pushes to Type Word II

## Intuition

To minimize the total number of pushes, assign the **most frequent characters** to the **lowest push cost**.

* First 8 characters → 1 push
* Next 8 characters → 2 pushes
* Next 8 characters → 3 pushes
* ...

So:

1. Count the frequency of each character.
2. Sort the frequencies in descending order.
3. Multiply each frequency by its assigned push cost.

The push cost is computed as:

```python
i // 8 + 1
```

where `i` is the index in the sorted frequency list.

## Complexity

* **Time:** `O(n)`
* **Space:** `O(1)` (at most 26 lowercase letters)

## Mistakes

* Sorting frequencies in ascending order.
* Forgetting `reverse=True`.
* Using `i // 8` instead of `i // 8 + 1` (first group would get cost `0`).
* Using `%` instead of `//` for grouping.
