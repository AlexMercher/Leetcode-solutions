## Explanation

# Minimum Path Sum — Explanation

Define:

```cpp
dp[i][j] = minimum cost to reach cell (i,j)

For an interior cell, the robot can come from either:

top: (i-1, j)
left: (i, j-1)

Therefore:

dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1]);

The first row and first column need separate initialization because they have only one possible direction:

dp[0][j] = dp[0][j-1] + grid[0][j];
dp[i][0] = dp[i-1][0] + grid[i][0];

The starting cell is:

dp[0][0] = grid[0][0];

The answer is:

dp[m-1][n-1]

This is a standard grid DP pattern:

boundary → only one predecessor
interior → top + left, choose min

Time: O(m × n)
Space: O(m × n)

## My Notes


# Mistakes

1. Do not use the interior recurrence for `(0,j)` or `(i,0)` because one predecessor is out of bounds.
2. Initialize `dp[0][0]` with `grid[0][0]`.
3. First row uses only the left cell.
4. First column uses only the top cell.
5. Interior cells use `min(top, left) + current`.
