## Explanation

# Generate All Unique Structures — Explanation

This is a **Choose → Recurse → Combine** pattern.

We want to generate every valid structure.

For Unique BST II:

```text
solve(lo, hi)

means: generate all BSTs using values from lo to hi.

For every possible value root:

left  = solve(lo, root - 1)
right = solve(root + 1, hi)

The left subtree contains smaller values and the right subtree contains larger values.

Then combine every left tree with every right tree:

for each L in left
    for each R in right
        create root
        root.left = L
        root.right = R
        add to answer

Base case:

if (lo > hi)
    return {nullptr};

We return one empty structure because the parent still needs to combine it with the other side.

Generic Pattern
Choose
  ↓
Break into independent subproblems
  ↓
Recursively generate all possibilities
  ↓
Cartesian-product the results
  ↓
Collect every valid answer

Other “generate all valid structures” problems

## My Notes

# Mistakes

1. Do not generate only one root; try every possible choice.
2. Left and right parts must be generated independently.
3. Combine every left result with every right result.
4. Base case must return `{nullptr}`, not an empty vector.
5. Do not forget to return/collect every generated structure.
6. Think: Choose → Recurse → Combine.
