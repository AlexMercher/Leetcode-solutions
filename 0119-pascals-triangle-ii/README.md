## Explanation

We keep iterating only over the same row while adding the prev in the same row and thus building the rowIndex in the same run.

# Pascal's Triangle Row — Solution + Dry Run

## Idea

We only need the requested row, so we can build Pascal's Triangle **in-place using one vector**.

Start with:

```cpp
vector<int> row(rowIndex + 1, 1);

All positions are initially 1 because the first and last elements of every Pascal row are 1.

Then build each row from 1 to rowIndex.

The important part is iterating backwards:

for(int j = i; j > 0; j--)
    row[j] += row[j - 1];

Going backwards prevents an already-updated value from being reused in the same iteration.

Code
class Solution {
public:
    vector<int> getRow(int rowIndex) {
        vector<int> row(rowIndex + 1, 1);


        for(int i = 1; i < rowIndex; i++) {
            for(int j = i; j > 0; j--) {
                row[j] += row[j - 1];
            }
        }


        return row;
    }
};
Dry Run

Suppose:

rowIndex = 3

Initial:

row = [1, 1, 1, 1]
i = 1
j = 1


row[1] += row[0]
row[1] = 1 + 1 = 2

Now:

[1, 2, 1, 1]

This represents:

[1,2,1]

with the unused final position still present.

i = 2

Start:

[1,2,1,1]
j = 2
row[2] += row[1]
1 + 2 = 3
[1,2,3,1]
j = 1
row[1] += row[0]
2 + 1 = 3
[1,3,3,1]

Final answer:

[1,3,3,1]
Why Iterate Backwards?

If we went forward:

for(int j = 1; j <= i; j++)

then row[j - 1] might already contain the new value from the current row, which would corrupt the calculation.

Backward traversal ensures:

row[j - 1]

is still the value from the previous row.

Complexity
Time:  O(rowIndex²)
Space: O(rowIndex)
