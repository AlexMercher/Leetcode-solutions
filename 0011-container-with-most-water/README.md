## Explanation

For:

[1,8,6,2,5,4,8,3,7]

Initially:

left = 0 → 1
right = 8 → 7

area = min(1,7) * 8 = 8

Left is shorter → move left.

Eventually:

left = 1 → 8
right = 8 → 7

area = min(8,7) * 7
     = 49

max_area = 49.

Complexity:

Time  = O(n)
Space = O(1)

The pattern to remember is:

area = shorter height × width → move the shorter side.
