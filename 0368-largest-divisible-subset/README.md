## Explanation

Take the array and sort it.
[1,2,3,4,8]

Once sorted, if:

nums[j] < nums[i]

then for the pair (j,i), the condition can only be satisfied by:

nums[i] % nums[j] == 0

So define:

dp[i] = size of the largest divisible subset
       whose last/largest element is nums[i]

Then:

if(nums[i] % nums[j] == 0)
    dp[i] = max(dp[i], dp[j] + 1);

But there is an important detail: we also need to reconstruct the actual subset, not just its size. So keep a parent array.

Example
nums = [1,2,3,8]

After sorting:

i = 0 → 1
dp[0] = 1

i = 1 → 2
1 divides 2
dp[1] = 2

i = 2 → 3
1 divides 3
dp[2] = 2

i = 3 → 8
1 divides 8
2 divides 8

dp[3] = 3

The best chain is:

1 → 2 → 8
