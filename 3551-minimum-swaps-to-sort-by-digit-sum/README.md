## Explanation

The goal is to place target[i] at the correct position i using one swap whenever necessary.
for (int i = 0; i < cur.size(); i++) {
    if (cur[i] == target[i]) continue;

    int j = pos[target[i]];

    swap(cur[i], cur[j]);

    pos[cur[i]] = i;
    pos[cur[j]] = j;

    swaps++;
}


Line by line:
1. if (cur[i] == target[i]) continue;
   The element is already correct, so skip it.
2. int j = pos[target[i]];
   Find where the element we need is currently located.
3. swap(cur[i], cur[j]);
   Swap it into its correct position i.
4. pos[cur[i]] = i; pos[cur[j]] = j;
   Update the map because the two elements changed positions.
5. swaps++;
   Count the swap performed.
Example:
cur    = [18, 43, 34, 16]
target = [16, 34, 43, 18]


At i = 0, we need 16, which is at index 3. Swap them:
cur = [16, 43, 34, 18]


One swap done, and index 0 is now permanently correct.
Key idea: Fix one position at a time by bringing the required element directly to it.
