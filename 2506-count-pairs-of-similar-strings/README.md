## Explanation

For a word like:

"aba"

you set:

a → bit 0
b → bit 1

So the mask becomes:

0011

The second a doesn't change anything because that bit is already 1.

Thus:

"aba" → 0011
"ab"  → 0011
"aab" → 0011

All represent the same set of distinct characters, so they are similar.

## My Notes

### Mistakes

The only mistake was the vector declaration:

vector<int> mask(0, n);   // ❌
vector<int> mask(n, 0);   // ✅

Easy rule to remember:

vector<int> v(size, initial_value);

So:

vector<int> mask(n, 0);

means n zeros.
