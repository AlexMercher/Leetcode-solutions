## Explanation

The idea
Always reduce the largest difference first.
Instead of storing every difference in a heap, freq[x] tells us how many differences currently equal x.
For example:
Differences: [5, 5, 3, 1]

freq[5] = 2
freq[3] = 1
freq[1] = 1


Reducing both 5s to 4 costs two operations. We can process the entire group at once instead of simulating each operation individually.
