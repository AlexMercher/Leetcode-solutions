That splits the current subtree into left and right.

build(..., mid + 1, right)

builds the right subtree.
The most important mental model
Don't memorize the code first. Remember:
PREORDER:
root → left → right
   ↓
gives us the ROOT

INORDER:
left → root → right
          ↓
    tells us where to SPLIT

So:
Preorder tells me WHO the root is. Inorder tells me HOW to divide the tree.

That's the entire trick behind this problem.
