## Explanation

Why each pointer exists
For:
1 → 2 → 3 → 4 → 5

with k = 2:
groupPrev
   ↓
dummy → 1 → 2 → 3 → 4 → 5
             ↑
            kth

groupPrev marks the node before the group.
kth finds the last node of the group.
So:
group:
1 → 2

and:
groupNext = kth->next;

stores:
3

because after reversal we need to know where the group ends.
During reversal:
prev = groupNext
curr = groupPrev->next

For 1 → 2, this effectively produces:
2 → 1 → 3

Then:
groupPrev->next = kth;

connects the previous part to the new first node (2).
Finally:
groupPrev = temp;

moves groupPrev to the old first node, which is now the end of the reversed group (1), so we're positioned correctly for the next group.
Why the leftover nodes stay unchanged
The for loop searches for all k nodes:
for(int i = 0; i < k; i++) {
    kth = kth->next;

    if(kth == nullptr)
        return dummy.next;
}

Suppose only 2 nodes remain but k = 3.
We fail to find the third node, so we immediately return the list without reversing that group.
Complexity
Time:  O(n)
Space: O(1)

The key pattern is:
Find a complete group → reverse it → reconnect → repeat.
