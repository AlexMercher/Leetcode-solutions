## Explanation

For:

digits = "23"

We start at digit 2:

2 -> a
     b
     c

Take a.

curr = "a"

Now move to digit 3:

3 -> d
     e
     f

So we get:

ad
ae
af

Then we undo a:

curr = ""

Take b:

bd
be
bf

Then c:

cd
ce
cf

Final:

["ad","ae","af","bd","be","bf","cd","ce","cf"]
The important part

This:

curr.push_back(c);
backtrack(...);
curr.pop_back();

is the heart of backtracking.
