## Explanation

Imagine we fix the starting index i. We can extend the ending index j one position at a time.
For each new element:
- If we haven't seen it in this subarray, increase the distinct count.
- Add distinct * distinct to the answer.
We keep a seen array to track which values have appeared. Since nums[i] is between 1 and 100, a boolean array of size 101 is sufficient.
