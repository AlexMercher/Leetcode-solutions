## Explanation

The tricky part is the word distinct.

For ordinary subsequences, every character gives us a take/skip choice, so there are 2^n subsequences. But many of those can be identical.

For example:

s = "aaa"

There are 8 index-based subsequences, but the distinct strings are only:

"a"
"aa"
"aaa"

So we need DP that counts unique strings, not choices of indices.

1. The DP idea

Let:

dp[i]

mean:

Number of distinct subsequences of the first i characters, including the empty subsequence.

Start with:

dp[0] = 1;

because the empty string is one subsequence.

Now suppose we are processing:

s[i-1]

For every existing subsequence, we can append this character.

So at first glance:

dp[i] = 2 * dp[i-1]

because:

old subsequences
+
old subsequences + s[i-1]

But this double-counts whenever the current character has appeared before.

2. Where the duplicates come from

Take:

s = "aba"

After "ab" the distinct subsequences are:

""
"a"
"b"
"ab"

So:

dp = 4

Now process the final 'a'.

Appending 'a' to everything gives:

"a"
"aa"
"ba"
"aba"

But "a" was already present.

So:

4 old
+
4 newly generated
-
1 duplicate
=
7

Indeed the distinct subsequences including empty are:

""
"a"
"b"
"ab"
"aa"
"ba"
"aba"

So:

dp = 7

We will return dp[n] - 1 because the problem asks for non-empty subsequences.

3. The important observation

Suppose the current character is c.

Let:

last[c]

be the number of distinct subsequences before the previous occurrence of c.

Then the newly generated subsequences from the current c are exactly the duplicates that were created when we previously processed c.

So:

new dp
=
2 * old dp
-
last[c]

Then we update:

last[c] = old dp
4. Example: "aaa"

Let's track it.

Initially:

dp = 1
last[a] = 0
First 'a'
dp = 2 * 1 - 0 = 2

Subsequences:

""
"a"

Update:

last[a] = 1
Second 'a'

Old:

dp = 2

So:

dp = 2 * 2 - last[a]
   = 4 - 1
   = 3

Subsequences:

""
"a"
"aa"

Update:

last[a] = 2
Third 'a'
dp = 2 * 3 - 2
   = 4

Subsequences:

""
"a"
"aa"
"aaa"

Return:

4 - 1 = 3
The + MOD is important because:

2 * dp - last[idx]

can become negative.

6. Why last[c] = oldDp?

This is the part people often memorize incorrectly.

Suppose we process character c for the first time.

Before processing it:

dp = X

Appending c creates X new subsequences.

So:

last[c] = X

Later, when c appears again, those are exactly the subsequences whose new copies might be duplicates.

Therefore we remember:

How many distinct subsequences existed just before the previous occurrence of this character?

That's what last[c] stores.

7. Another way to think about the recurrence

For each character:

             current character c
                      |
           -----------------------
           |                     |
    don't append c        append c
           |                     |
        dp[i-1]             dp[i-1]
                                |
                         duplicates exist
                                |
                         subtract last[c]

Therefore:

dp[i] = 2 * dp[i-1] - last[c]
8. Why this works so nicely

Without duplicates:

each existing subsequence
        ↓
two choices
    don't use c
    use c
        ↓
2 × dp

The only issue is duplicate strings.

And duplicates can only happen because the same character appeared before.

So we don't need to remember the whole set of subsequences. We only need:

last[26]

one value for each possible lowercase letter.

9. Complexity

There are n characters and 26 possible letters:

Time  = O(n)
Space = O(26) = O(1)

For n <= 2000, this is easily fast enough.
