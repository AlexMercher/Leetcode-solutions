## Explanation

odd-only optimized Sieve of Eratosthenes.

We combine three optimizations:

1. Ignore even numbers
2. Start marking from i²
3. When marking, jump by 2i

For example, with i = 5:

25  ← mark
30  ← skip (even)
35  ← mark
40  ← skip
45  ← mark
...

So we don't waste work touching even numbers.

And vector<bool> is perfectly fine here. It stores the boolean sieve in a packed representation, so memory usage is very small.
