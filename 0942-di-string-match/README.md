## Explanation

The main idea

A consecutive D section:

DDD

needs:

a > b > c > d

So starting with increasing numbers:

1 2 3 4

we simply reverse them:

4 3 2 1

For an I:

a < b

the increasing order already works.

So the pattern is:

I   → leave alone
DDD → reverse that entire block
D   → reverse those 2 numbers

Time complexity is O(n) overall, because the reversals together touch each element only a constant number of times.
