## Explanation

Suppose:

s = "loveleetcode"

We put everything into the queue:

front
  ↓
(l,0) (o,1) (v,2) (e,3) (l,4) ...

The frequency array tells us:

l → 2
o → 2
v → 1
e → 3

Now inspect from the front:

l → freq = 2 → not unique → pop
o → freq = 2 → not unique → pop
v → freq = 1 → unique → return index 2

So:

answer = 2
Why store the index?

Because the question asks for the index, not the character.

That's why we store:

q.push({s[i], i});

instead of just:

q.push(s[i]);
Pattern

This is a useful combination to recognize:

Need first/earliest item satisfying some condition
        +
Need to know whether item is still valid
        ↓
Queue + frequency/count/map

Here:

Queue     → preserves original order
freq[]    → tells whether character is unique
