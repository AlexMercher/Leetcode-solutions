## Explanation

How BFS works
For the graph 1 — 2 — 3:
Start:
Queue = [1]
Clones = {1}

Process 1:
Create clone 2
Connect clone 1 → clone 2
Queue = [2]

Process 2:
Clone 1 already exists
Create clone 3
Connect clone 2 → clone 1 and clone 3
Queue = [3]

Process 3:
Clone 2 already exists
Connect clone 3 → clone 2
Queue = []


The cloned graph has its own nodes and edges, separate from the original graph.
