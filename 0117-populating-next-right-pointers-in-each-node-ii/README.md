## Explanation

The mental model

At each level:

current level:
A → B → C → D → NULL

Use this existing next chain to build:

next level:
children of A → children of B → children of C → children of D

Then move down:

A → B → C
     ↓
a → b → c → d

The program processes the tree level by level using the next pointers themselves.

Node* curr = root;

curr points to the first node of the current level.

1. Create a dummy node
Node dummy(0);
Node* tail = &dummy;

dummy.next will become the first node of the next level.

tail keeps track of the last child we've added.

2. Traverse the current level
while(curr != nullptr)

Because the current level's next pointers are already connected, we can simply move:

A → B → C → D → NULL

For every node, add its children:

if(curr->left != nullptr) {
    tail->next = curr->left;
    tail = tail->next;
}

if(curr->right != nullptr) {
    tail->next = curr->right;
    tail = tail->next;
}

So if the current level is:

1 → 2 → 3 → NULL

and their children are:

    1
   / \
  4   5

    2
     \
      6

    3
     \
      7

we build:

4 → 5 → 6 → 7 → NULL
3. Move to the next level

After finishing the current level:

curr = dummy.next;

Now curr points to the first node of the next level.

Then the whole process repeats.

The key idea
Current level's next pointers
          ↓
      traverse level
          ↓
   connect all children
          ↓
   children become next level
          ↓
        repeat

The dummy node is just a convenient temporary starting point so we don't have to separately find the first child.
