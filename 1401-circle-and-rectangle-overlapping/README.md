## Explanation

1. Find the closest x

The rectangle's x-range is:

[x1, x2]

So:

closestX = clamp(xCenter, x1, x2);

Meaning:

if xCenter < x1, use x1
if xCenter > x2, use x2
otherwise use xCenter

Similarly for y:

closestY = clamp(yCenter, y1, y2);

Then the closest point in the rectangle is:

(closestX, closestY)
2. Check distance

Circle equation:

$$ (x-x_c)^2 + (y-y_c)^2 \le r^2 $$

So:

dx = closestX - xCenter;
dy = closestY - yCenter;

and check:

dx*dx + dy*dy <= radius*radius

Dry run: Example 1
radius = 1
center = (0,0)

rectangle:
x = [1,3]
y = [-1,1]

Closest point to (0,0) is:

closestX = 1
closestY = 0

Distance squared:

(1-0)^2 + (0-0)^2
= 1

Radius squared:

1^2 = 1

So:

1 <= 1 ✅

Therefore they overlap.

Example 2
center = (1,1)
radius = 1

rectangle:
x = [1,2]
y = [-3,-1]

Closest point:

(1,-1)

Distance squared:

(1-1)^2 + (-1-1)^2
= 4

Radius squared:

1

So:

4 <= 1 ❌

No overlap.

The mental model
Circle center
     ↓
Find closest point inside rectangle
     ↓
Measure distance to that point
     ↓
distance <= radius ?
     ↓
yes → overlap
no  → no overlap
