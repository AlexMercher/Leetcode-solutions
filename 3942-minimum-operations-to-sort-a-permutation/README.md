## Explanation

The target is:
[0, 1, 2, ..., n-1]


There are only two kinds of arrays we can transform into this target.

Pattern A: Circularly increasing

Examples for n = 4:
[0, 1, 2, 3]   already sorted
[2, 3, 0, 1]   circularly increasing
[3, 0, 1, 2]   circularly increasing


Each next element is (previous + 1) % n.

Pattern B: Circularly decreasing

Examples for n = 4:
[3, 2, 1, 0]
[1, 0, 3, 2]
[0, 3, 2, 1]


Each next element is (previous - 1 + n) % n.

If the array matches neither pattern, return -1.
2. Calculate the minimum operations
Case A: Circularly increasing
Let d be the index of 0.

We can sort the array with d left rotations.

But sometimes we can do better by reversing, rotating, and reversing again. This effectively rotates in the opposite direction and costs n - d + 2 operations.

Thus:
min(d,n-d+2)

For example, with [3,0,1,2], d = 1. One left rotation sorts it, so the answer is 1.

Case B: Circularly decreasing
Let k = n - 1 - nums[0]. This tells us how far the array is rotated from the fully decreasing sequence.

We need one reversal, plus rotations in either direction. The two options cost k + 1 or n - k + 1.

Therefore:		min(k,n-k)+1
For [0,2,1], n = 3 and k = 2, so the answer is 1+min(2,1)=2.
