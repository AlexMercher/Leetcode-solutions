## Explanation

The stack represents:
Opening brackets that are currently waiting for a matching ).

When we see '(':
st.push(c);

we create a requirement for a future ')'.
When we see ')':
if(st.empty())
    ans++;

there is nothing available to match it, so we must insert an '(' somewhere before it.
Otherwise:
st.pop();

we have successfully matched that ')' with an existing '('.
At the end, anything left in the stack is an unmatched '(':
while(!st.empty()){
    st.pop();
    ans++;
}

Each one needs a ')'.
Example: ())
char    stack       ans

(       (            0
)       empty        0
)       empty        1

The second ) has nothing to match, so we need one inserted (.
Answer:
1
