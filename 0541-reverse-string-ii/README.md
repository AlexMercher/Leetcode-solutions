## Explanation

Idea

For every starting index:

i = 0, 2k, 4k, 6k, ...

reverse:

[i, i + k - 1]

But don't go past the end of the string.

min(i + k - 1, n - 1) handles both special cases automatically.

Dry run
s = "abcdefg"
k = 2

First chunk:

[a b] c d e f g
 ↓
[b a] c d e f g

i = 4 next:

b a c d [e f] g
         ↓
b a c d f e g

i = 8 → stop.

Result:

"bacdfeg"
Why 2*k?

Because each block is:

k characters → reverse
k characters → leave unchanged

So:

| reverse k | untouched k | reverse k | untouched k | ...
      <--------- 2k --------->
