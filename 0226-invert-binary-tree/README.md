## Explanation

Original:

    1
   /
  2

Swap:

    1
     \
      2

which is:

[1,null,2]

The important distinction is:

if(root->left && root->right)

means "swap only if both exist".

But we need:

swap(root->left, root->right);

because nullptr is also a valid child pointer that needs to be moved.
