## Explanation

For:

s = "(name)is(age)"
knowledge = [["name","bob"],["age","two"]]

Hashmap:

"name" -> "bob"
"age"  -> "two"

Now scan:

i=0 → '('

Find ) at j=5.

key = "name"
mp["name"] = "bob"
ans = "bob"

Then:

i = j = 5

The for loop increments it to 6, which is 'i'.

Continue:
ans = "bobi"
ans = "bobis"

Then (age):
key = "age"
value = "two"
ans = "bobistwo"

Final:"bobistwo"

Complexity

Building the hashmap:O(knowledge.length)

Scanning the string:O(s.length)

So overall approximately:O(n + k)

where n = s.length and k = knowledge.length.
