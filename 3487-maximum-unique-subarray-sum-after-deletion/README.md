## Explanation

For:

[-100]

we get:

sum = 0
mx = -100

so:

return -100;

One subtle case:

[0, -5, -10]

If the problem requires selecting at least one element, the best answer is 0, and mx handles that too.

So the idea becomes:

positive distinct values exist
        ↓
take all of them

no positive values
        ↓
take the largest element
