## Explanation

Now let's dry-run the whole backspaceCompare

Take:

s = "ab#c"
t = "ad#c"
s
"ab#c"

Operations:

a → [a]
b → [a,b]
# → [a]
c → [a,c]

So:

op(s) = "ac"
t
"ad#c"

Operations:

a → [a]
d → [a,d]
# → [a]
c → [a,c]

So:

op(t) = "ac"

Then:

return s == t;

becomes:

return "ac" == "ac";

Therefore:

true
Let's also dry-run the important edge case
s = "ab##"
Process:
'a' → [a]
'b' → [a,b]
'#' → [a]
'#' → []

Then the second # works because of:

if(!st.empty())
    st.pop();

Without that check, you'd try to pop() an empty stack.

Then:

while(!st.empty())

doesn't run at all.

So:

a = ""

and:

reverse(a.begin(), a.end());

still gives:

""

Correct.

The whole function in one mental picture

For:

op(s)

there are really two stages:

STRING
   ↓
process characters
   ↓
STACK = final characters, reversed
   ↓
pop everything
   ↓
STRING is backwards
   ↓
reverse()
   ↓
actual final text

So for:

"ab#c"

you can think:

Input:       a b # c
             ↓ ↓   ↓
Stack:       a b   c
               ↑
            remove b

Final stack:

top → c
      a

Pop stack:

"ca"

Reverse:

"ac"
