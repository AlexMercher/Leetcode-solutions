## Explanation

Iterate over the string in target zone and if there is a mismatch then you just make sure that we construct the smallest characters lexicographically then we just return the string, Now if we exactly match the target then we need to shuffle and thus we need to ensure that we backtrack.

for(int i=min(int(ans.size()),n)-1;i>=0;i--){
            int cur=target[i]-'a';
            freq[cur]++; // We make sure that the frequency is updated for the last character as we need to update the frequency.

            for(int c=cur+1;c<26;c++){ // cur+1 because we need to ensure that we only see the character greater then the given characters.
                if(freq[c]==0) continue; // Iterate over all the available frequency of characters >  cur
                string res=target.substr(0,i); // Take a substring of the target till it matched.
                res.push_back('a'+c);
                freq[c]--;

                for(int x=0;x<26;x++) res+=string(freq[x],'a'+x); // constructing the lexicographical string.
                return res;
            }
        }
