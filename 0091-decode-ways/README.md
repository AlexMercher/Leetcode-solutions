# Decode Ways — Explanation

Define:

```cpp
dp[i] = number of ways to decode the first i characters
We use n + 1 states because dp[0] represents the empty prefix.

Base case:

dp[0] = 1;

For each position i:

1. Decode one digit

If s[i-1] != '0', the digit is valid (1 to 9):

dp[i] += dp[i-1];
2. Decode two digits

Form the number:

int num = (s[i-2]-'0') * 10 + (s[i-1]-'0');

If it lies between 10 and 26:

dp[i] += dp[i-2];

A leading zero is never valid, so "06" cannot be decoded.

Finally:

return dp[n];

Time: O(n)
Space: O(n)

---

## My Notes

1. `dp[0]` must be `1`, not `0`; it represents one way to decode an empty prefix.
2. Use `i <= n` because `dp[n]` is the final state.
3. A single digit `0` is invalid.
4. A two-digit code must be between `10` and `26`.
5. Codes like `"06"` are invalid because leading zeroes are not allowed.
6. `dp[i]` represents the first `i` characters, not index `i`.
