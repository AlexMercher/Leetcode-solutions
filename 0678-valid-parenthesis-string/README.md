## Explanation

')' arrives
   ↓
use '(' if possible
   ↓
otherwise use '*' as '('
   ↓
otherwise impossible

After scanning:
unmatched '(' remain
        ↓
use '*' as ')'
        ↓
but only stars that occur AFTER those '('

We must remember whether that "something" was a real ( or a *, and we must respect the positions of * when using them to close leftover (.
