## Explanation

Dry run: (u(love)i)

Start:

curr = ""

Read u:

curr = "u"

Read (:

stack = ["u"]
curr = ""

Read love:

curr = "love"

Read ):

reverse("love") = "evol"

curr = "u" + "evol"
     = "uevol"

stack = []

Read i:

curr = "uevoli"

Read final ):

reverse("uevoli") = "iloveu"

Answer:

"iloveu"
The key pattern

Think:

'(' → save outside, start inside
')' → reverse inside, attach to outside

The stack is needed because with nested parentheses, we have to remember what was outside the current pair.

Complexity:

Time:  O(n²) worst case
Space: O(n)

The O(n²) comes from repeated reverse() and string concatenation in deeply nested cases.
