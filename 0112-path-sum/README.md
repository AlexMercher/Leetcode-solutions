## Explanation

At each call:

targetSum = sum still needed from this node downward

So:

root->val == targetSum

is only enough when root is a leaf.

For example:

    5
   /
  4
 /
11

Target = 9

At 5:

remaining = 9

Go to 4:

remaining = 9 - 5 = 4

Go to 11:

remaining = 4 - 4 = 0

Now 11 is a leaf, but:

11 != 0

so false.
