## Explanation

Why the shifts are from -(n-1) to +(n-1)

Suppose n = 3.

The maximum useful shift is:

-2 ... 0 ... +2

A shift of +3 would move every cell completely outside the matrix, so the overlap would automatically be 0.

So there are:

5 × 5 = 25

possible meaningful translations.

Example

Suppose:

img1 =

1 1 0
0 1 0
0 1 0

and:

img2 =

0 0 0
0 1 1
0 0 1

Try:

dr = 1
dc = 1

That means:

(i, j) → (i+1, j+1)

for every 1 in img1.

The shifted image becomes effectively:

0 0 0
0 1 1
0 0 1

and the overlap is 3.

Complexity

There are:

(2n-1)^2 = O(n²)

translations.

For each translation, we inspect:

n²

cells.

Therefore:

Time = O(n⁴)
Space = O(1)

For n <= 30:

(59²) × 30² ≈ 3.1 million

cell checks, which is completely fine.
