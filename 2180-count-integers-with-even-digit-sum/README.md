## Explanation

Every number has exactly 5 elements that are there which have even sum from the range of n to n+10. So now we only need to check the one that we have if its sum is odd then we have to subtract one with the number and return its division by 2.
Eg:
30: Digits sum=3 => Odd.
Thus 30-1 =29.... Till 29 only we will get the digits with even sum and 29/2 gives 14 automatically. So yeah this is log(num) in Time Complexity.
