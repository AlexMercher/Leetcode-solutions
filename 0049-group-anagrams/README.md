## Explanation

For:

strs = ["eat","tea","tan","ate","nat","bat"]

Initially:

mp = {}
"eat"

Copy:

key = "eat"

Sort:

"aet"

So:

mp["aet"] = ["eat"]
"tea"

Sort:

"tea" → "aet"

Same key:

mp["aet"] = ["eat", "tea"]
"tan"
"tan" → "ant"

So:

mp["ant"] = ["tan"]
"ate"
"ate" → "aet"

So:

mp["aet"] = ["eat", "tea", "ate"]
"nat"
"nat" → "ant"

So:

mp["ant"] = ["tan", "nat"]
"bat"
"bat" → "abt"

So:

mp["abt"] = ["bat"]

At the end:

mp
│
├── "aet" → ["eat", "tea", "ate"]
├── "ant" → ["tan", "nat"]
└── "abt" → ["bat"]

Then we simply put each map value into ans:

[
    ["eat","tea","ate"],
    ["tan","nat"],
    ["bat"]
]

The order doesn't matter.

Why does sorting work?

Take:

eat
tea
ate

All three contain:

a → 1
e → 1
t → 1

Sorting produces the same canonical representation:

aet

But:

bat

contains:

a → 1
b → 1
t → 1

so it becomes:

Different key → different group.
