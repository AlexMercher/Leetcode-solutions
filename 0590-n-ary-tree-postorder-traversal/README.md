## Explanation

For N-ary postorder, the order is:

children → node

So for:

        1
      / | \
     3  2  4
    / \
   5   6

postorder is:

5 6 3 2 4 1
Easiest iterative trick

We already know how to do preorder:

node → children left to right

If instead we process:

node → children right to left

and then reverse the result, we get:

children left to right → node

Dry run

Tree:

        1
      / | \
     3  2  4
    / \
   5   6

Start:

stack = [1]
ans = []

Pop 1:

ans = [1]

Push children left → right:

stack = [3,2,4]

Pop 4:

ans = [1,4]

Pop 2:

ans = [1,4,2]

Pop 3:

ans = [1,4,2,3]

Push 3's children 5,6:

stack = [5,6]

Pop 6:

ans = [1,4,2,3,6]

Pop 5:

ans = [1,4,2,3,6,5]

Now reverse:

[5,6,3,2,4,1]

which is exactly postorder.

The pattern
Preorder:
node → left → right

Postorder:
left → right → node

For N-ary:

node → children (right → left)

then:

reverse result

So the mental trick is:

Reverse preorder = postorder, provided you arrange the child processing appropriately.
