## Explanation

The mental model
Think of the two heaps as:
MAX HEAP                 MIN HEAP
smaller half             larger half

1  2 | 3  4  5
    ↑   ↑
   top top

left.top() = largest small number
right.top() = smallest large number
Those are exactly the numbers you need to know to find the median.
So whenever you see:
stream of numbers + repeatedly ask for median

think:
two heaps → max heap for lower half + min heap for upper half.
And the reason this is efficient is that addNum() only does heap operations, so:
addNum     O(log n)
findMedian O(1)

Space is O(n).
