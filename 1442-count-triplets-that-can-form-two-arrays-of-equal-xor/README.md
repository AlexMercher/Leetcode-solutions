## Explanation

The main observation is that they want a==b so their xor will also be 0 now we have to find the i,j and k such that 0<=i<j<=k 

a=arr[i]^arr[i+1]^.......^arr[j-1];
b = arr[j]^arr[j + 1]^...^arr[k];

Now if a==b then from i to k we need to find the range where xor can be 0; Now the possible values of j for the given range i to k can be (k-i) Hence we add that.
