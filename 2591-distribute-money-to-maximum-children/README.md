## Explanation

Iterate till the money is not over;
Use Greedy approach for maximizing the no of children who can get 8.
while(money>=7 && i<children){
            ans[i++]+=7;
            money-=7;
        }
### Base cases:
if(money<children) return -1;
if(money==8*children) return children;
money-=children; Each children should get at least 1$.
