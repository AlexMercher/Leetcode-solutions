Element	Prefix sum	Parity	Odd subarrays added		Answer
1	1	Odd	1 (previous even prefixes)	1
3	4	Even	1 (previous odd prefixes)	2
5	9	Odd	2 (previous even prefixes)	4

Final answer: 4

For a subarray sum to be:
- Even: Both prefix sums must have the same parity.
- Odd: The two prefix sums must have different parity.
This technique is useful for many problems involving odd/even subarray sums.

We maintain three variables:
long long even = 1;
long long odd = 0;
long long ans = 0;

Why do we initialize even = 1?

Because before processing any element, the empty prefix has a sum of 0, which is even.

This allows us to count subarrays starting at index 0.
Step 1: Process every element
For each element, we determine whether the current prefix sum is odd or even.
