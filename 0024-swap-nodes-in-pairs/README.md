## Explanation

Before:

prev → slow → fast → next

After:

prev → fast → slow → next

Do exactly:

slow->next = fast->next;
fast->next = slow;
prev->next = fast;

Then:

prev = slow;
slow = slow->next;
fast = slow->next;
