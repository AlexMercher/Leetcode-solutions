## Explanation

We make the F(0) array and then ensure that we get the solution in O(1) space by using the 

F=F+sum-n*nums[n-k];

So basically we add all the elements in the array once more and then ensure that we delete the one last element which was supposed to be muliplied by 0 hence we substract the n*nums[n-k] from the F and taking ans=max(ans,F) is just the optimal way to keep track of the max element.
