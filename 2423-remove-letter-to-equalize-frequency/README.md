## Explanation

Core Idea

First count how many times each character appears:

cnt = Counter(word)

Then count how many characters have each frequency:

freqs = Counter(cnt.values())

For example:

word = "abbcc"

character frequencies:
a → 1
b → 2
c → 2

freqs:
1 → 1 character
2 → 2 characters

Now we only need to reason about the frequency distribution.

Case 1: One distinct frequency
if len(freqs) == 1:

All characters have the same frequency.

This is valid only when:

frequency is 1: removing any character leaves all remaining frequencies equal.
there is only one character with that frequency: removing one occurrence still leaves only one distinct character.
return f == 1 or c == 1
Case 2: Two distinct frequencies

Sort them:

(f1, c1), (f2, c2)

Two possibilities are valid.

Unique frequency-1 character
if f1 == 1 and c1 == 1:
    return True

Example:

[1, 2, 2]

Remove the character occurring once.

Unique maximum frequency
if f2 - f1 == 1 and c2 == 1:
    return True

Example:

[2, 2, 3]

Remove one occurrence from the character with frequency 3.

Any other frequency distribution cannot be fixed with exactly one deletion.

Complexity

Counter processes the string in O(n) time.

Since there are at most 26 distinct letters:

Time:  O(n)
Space: O(1)

## My Notes

Mistakes
1. Comparing character frequencies directly

The important thing is not which characters have which frequencies.

We only care about the distribution of frequencies.

Instead of:

a → 2

b → 3
c → 3

think:

frequency 2 → 1 character
frequency 3 → 2 characters

That's why the second Counter is useful.

2. Assuming frequencies can differ only by 1

A case like:

[1, 3]

is valid.

Remove the character with frequency 1 entirely:

[3]

So a difference greater than 1 isn't automatically invalid.

3. Forgetting that exactly one character must be removed

If:

[2, 2]

the frequencies are already equal, but removing one character produces:

[1, 2]

so the answer is False.

Therefore, equal frequencies are valid only when:

frequency == 1

or there is only one distinct character.

4. Not considering removal of the entire minimum-frequency character

For:

[1, 2, 2]

we remove the character occurring once.

The result is:

[2, 2]

This is why:

f1 == 1 and c1 == 1

is a separate valid case.

5. Not requiring the higher frequency to be unique

For:

[2, 3, 3]

removing one from either 3 gives:

[2, 3]

which is still invalid.

Therefore:

f2 - f1 == 1 and c2 == 1

requires exactly one character to have the higher frequency.
