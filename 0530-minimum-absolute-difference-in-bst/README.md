## Explanation

The key property of a Binary Search Tree is:

Inorder traversal of a BST gives the values in sorted order.

And once the values are sorted, the minimum absolute difference can only occur between adjacent values.

Example
        4
       / \
      2   6
     / \
    1   3

Inorder:

1 2 3 4 6

Adjacent differences:

2-1 = 1
3-2 = 1
4-3 = 1
6-4 = 2

Answer = 1.

So we can do an inorder traversal while remembering the previous value.
