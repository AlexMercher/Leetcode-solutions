## Explanation

The important difference from your Trie
Your previous Trie had:
bool search(string word)

where every character gives exactly one path.
Here:
if(c != '.')

gives one path.
But:
if(c == '.')

creates up to 26 possible paths.
So the mental model is:
Normal character = move.
Dot = branch.
isEnd = did this branch form a complete stored word?

For the constraint of at most 2 dots, this branching stays quite manageable.

## My Notes

### Two mistakes:
1. In addWord()
curr->isEnd = false;

❌ You were marking the end as not a word.
It should be:
curr->isEnd = true;

2. In dfs()
if(index == word.size()) return true;

❌ You were saying “matching all characters means success.”
But it could just be a prefix.
Use:
if(index == word.size()) return curr->isEnd;

Remember
index == word.size() → Did I finish the query?
curr->isEnd          → Does a stored word finish here?

That distinction was the main issue.
