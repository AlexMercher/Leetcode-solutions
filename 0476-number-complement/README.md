## Explanation

~num also negates the furthur 0 bits hence we get -(nums+1) which is not the required answer so we need to make a mask and only change the bits that are there so we make the mask using mask=mask<<1 | 1; then we make sure that we do ~num & mask; This returns the optimal compliment.
