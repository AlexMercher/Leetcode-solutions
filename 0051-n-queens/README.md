## Explanation

What each structure means
board
→ actual chessboard

cols[c]
→ is column c already occupied?

diag[d]
→ is this main diagonal occupied?

antiDiag[d]
→ is this anti-diagonal occupied?

For example, when placing a queen at:
(row, col) = (2, 1)

we mark:
cols[1] = 1;
diag[2 - 1 + n - 1] = 1;
antiDiag[2 + 1] = 1;

So when another position is checked, we can immediately tell whether it conflicts.
The backtracking pattern
Think:
try a column
    ↓
mark row's queen
    ↓
go to next row
    ↓
if successful → keep it
if failure → undo

The undo is essential:
board[row][col] = '.';
cols[col] = 0;
diag[d1] = 0;
antiDiag[d2] = 0;

That's what allows the same column/diagonal to be tried in a different branch.
For n = 4, one branch might look like:
row 0 → col 1
row 1 → col 3
row 2 → no valid column
        ↓
      undo row 1
        ↓
try row 1 → col 0
...

So your initial thought was exactly right:
Backtracking + column set + main diagonal set + anti-diagonal set.

The important trick is using row-col+n-1 and row+col so diagonal checking becomes constant time.
