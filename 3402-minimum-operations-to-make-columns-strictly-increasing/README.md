## Explanation

We want each column to be strictly increasing.

So compare:

grid[i][j]

with the value above it:

grid[i-1][j]

If:

grid[i][j] <= grid[i-1][j]

we need to increase the current value until:

grid[i][j] > grid[i-1][j]

The exact amount needed is:

grid[i-1][j] - grid[i][j] + 1
