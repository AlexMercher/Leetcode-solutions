## Explanation

Case 1: Make everything EVEN

An odd number needs to become even.

The only way is:

odd - odd = even

So every odd number would need a smaller odd number.

But the smallest odd number cannot have a smaller odd number.

Therefore:

If there is even a single odd number, making everything even is impossible.

So all-even is possible only when every element is already even.

Example:

[4, 6]

Just keep both:

4, 6
Case 2: Make everything ODD

An odd number is already fine:

odd → keep it

An even number needs:

even - odd = odd

So every even number needs a smaller odd number.

What matters is the smallest element in the entire array:

If the minimum is odd

Suppose:

[1, 4, 7]

1 stays as 1.

Every larger even number can subtract 1:

4 - 1 = 3

So everything can be odd.

If the minimum is even and there is an odd number

Example:

[2, 3]

2 cannot become odd because there is no smaller odd number.

It cannot stay even either, because we want everything odd.

Therefore impossible.

Final condition

There are only two possibilities:

ALL EVEN:
    every number is even

OR

ALL ODD:
    smallest number is odd
