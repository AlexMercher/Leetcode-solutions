## Explanation

Take:

nums = [1,3,2,2,5,2,3,7]

Frequency:

1 → 1
2 → 3
3 → 2
5 → 1
7 → 1

Check adjacent values:

1,2 → 1 + 3 = 4
2,3 → 3 + 2 = 5
3,4 → 2 + 0 = invalid

So:

answer = 5

The subsequence can be:

[3,2,2,2,3]

Notice that subsequence does not mean contiguous. We can take every 2 and every 3 while preserving their original order.

Why not use x and x+2?

Because the difference would be:

(x + 2) - x = 2

but we need:

max - min == 1

Therefore only consecutive values matter:

x and x+1
