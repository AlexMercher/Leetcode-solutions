# Stone Game IX — Explanation

## 1. Reduce every stone using `% 3`

We only care whether the running sum is divisible by `3`.

Therefore every stone belongs to one of three groups:

```text
x % 3 == 0 → group 0
x % 3 == 1 → group 1
x % 3 == 2 → group 2

The important mental model

Don't memorize the formula first. Remember the chain:

          ↓

          ↓
0 doesn't change the remainder

          ↓

          ↓

          ↓

Odd 0s  → need a sufficiently large imbalance
