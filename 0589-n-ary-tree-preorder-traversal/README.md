## Explanation

For iterative preorder traversal, the rule is:

Visit the node first, then visit all its children from left to right.

For an N-ary tree:

        1
      / | \
     3  2  4
    / \
   5   6

Preorder:

1 → 3 → 5 → 6 → 2 → 4
Iterative trick

A stack is LIFO (last in, first out).

So if children are:

3, 2, 4

and we want to process them in:

3 → 2 → 4

we must push them in reverse:

4 → 2 → 3

Then 3 comes out first.
