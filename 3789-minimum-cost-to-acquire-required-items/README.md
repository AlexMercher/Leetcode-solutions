## Explanation

Option 1: Buy everything individually
long long direct = 1LL * cost1 * need1
                 + 1LL * cost2 * need2;


Option 2: Buy type 3 items for the common requirement and individual items for the remaining requirement.
long long mixed = mn * costBoth
                + 1LL * (need1 - mn) * cost1
                + 1LL * (need2 - mn) * cost2;


Option 3: Buy everything using type 3 items.
long long both = mx * costBoth;
