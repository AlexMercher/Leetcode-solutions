## Explanation

Let's trace it

For:

1 → 2 → 3 → 4 → 5
left = 2
right = 4

After finding prev:

dummy → 1 → 2 → 3 → 4 → 5
          ↑
         prev

curr is 2.

First iteration

Take 3:

next = 3

Detach it:

2 → 4

Put 3 immediately after prev:

1 → 3 → 2 → 4 → 5
Second iteration

Take 4:

1 → 4 → 3 → 2 → 5

Done.

The key pointer operation

This is the part worth memorizing:

ListNode* next = curr->next;

curr->next = next->next;
next->next = prev->next;
prev->next = next;

It transforms:

prev → curr → next

into:

prev → next → curr

while keeping the rest of the list connected.
