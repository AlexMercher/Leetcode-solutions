## Explanation

Dry run: n = 3, s = 20
i = 0:
x = 9
ans = "9"
s = 11

i = 1:
x = 9
ans = "99"
s = 2

i = 2:
x = 2
ans = "992"
s = 0

Answer:

992

Check:

9 + 9 + 2 = 20

And it's maximum because we made the first digit as large as possible, then the second, and so on.

One important detail

This:

x = min(9, s);

is the whole greedy rule:

put the maximum possible digit at the current position
→ reduce remaining sum
→ move to next position

So this is basically lexicographically maximizing the digits from left to right.
