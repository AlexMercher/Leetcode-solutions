## Explanation

Previously:
Level → store ALL nodes

Now:
Level → store ONLY the last node

So it's not really a new traversal pattern.
It's:
Level-order BFS
       ↓
know level size
       ↓
process exactly that many nodes
       ↓
take the last one

One subtle point: "rightmost" here means last node encountered in that BFS level, which is why we enqueue left first and right second.
