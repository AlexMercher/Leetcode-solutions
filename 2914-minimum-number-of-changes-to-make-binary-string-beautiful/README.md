## Explanation

Since every substring must have an even length, its ending boundary must also be at an even position.

Therefore, we cannot separate the two characters of any of these pairs:
(s[0], s[1])
(s[2], s[3])
(s[4], s[5])
...

For every pair:
- If both characters are equal, we need zero changes.
- If they are different, we need exactly one change.
For example:
s = "10110000"

Pairs:
10 | 11 | 00 | 00

Required changes:
10 → 00  (1 change)
11 → 11  (0 changes)
00 → 00  (0 changes)
00 → 00  (0 changes)

Result:
00110000

00 | 11 | 0000

All substrings are beautiful.

Total changes = 1.
