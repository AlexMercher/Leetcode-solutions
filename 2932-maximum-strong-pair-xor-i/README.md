## Explanation

1. Simplify the strong-pair condition

You have:

abs(nums[i] - nums[j]) <= min(nums[i], nums[j])

Because all numbers are positive, this is equivalent to:

max(a,b) <= 2 * min(a,b)

So instead of abs + min, you can write:

max(nums[i], nums[j]) <= 2 * min(nums[i], nums[j])
