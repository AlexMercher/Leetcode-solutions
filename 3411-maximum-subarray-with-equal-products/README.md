## Explanation

2. The important mathematical observation
There are two special cases:
- A subarray containing one element is always product equivalent.
- A subarray containing two elements is also always product equivalent.
Why?

For any two positive integers a and b:
 a x b=gcd(a,b) x lcm(a,b)
Therefore, every subarray of length 1 or 2 is valid.

For subarrays of length 3 or greater, we have another important property:
Pairwise coprime means that the GCD of every pair of elements must be 1.

For example:
[3, 4, 5]


All pairs have GCD 1:
gcd(3,4) = 1
gcd(3,5) = 1
gcd(4,5) = 1


Hence, it is product equivalent.

But:
[2, 3, 4]


We have:
gcd(2,3) = 1
gcd(2,4) = 2
gcd(3,4) = 1


Since one pair has GCD greater than 1, the subarray is not product equivalent.

Our problem has now become: Find the longest pairwise-coprime subarray, while remembering that every subarray of length 1 or 2 is automatically valid.
3. Approach: Sliding Window + GCD
We maintain two pointers:
int left = 0;
int ans = 2;


Why initialize ans = 2?

Because the constraints guarantee that the array contains at least two elements, and every subarray of length 2 is product equivalent.

We extend the right pointer one element at a time.

Whenever we add a new element, we check its GCD with all previously encountered elements.

If any pair has GCD greater than 1, those two elements cannot belong to the same valid pairwise-coprime subarray.

Therefore, we move the left pointer beyond the conflicting previous element.
Step 1: Iterate through the array
for (int right = 0; right < n; right++) {


The current element is:
nums[right]


We need to check whether it is coprime with the previous elements.
Step 2: Check GCD with previous elements
for (int i = 0; i < right; i++) {

    if (gcd(nums[i], nums[right]) != 1) {
        left = max(left, i + 1);
    }
}


Why do we set:
left = max(left, i + 1);


Suppose:
nums = [2, 3, 4]


When we reach 4:
gcd(2, 4) = 2


Therefore, indices 0 and 2 cannot belong to the same pairwise-coprime subarray.

We move left to at least index 1.

Our current valid window becomes:
[3, 4]


Notice that we don't necessarily reject the entire subarray. We simply remove the conflicting element from the left side.

We check every previous index because the new element might share a factor with multiple elements.
Step 3: Update the maximum length
ans = max(ans, right - left + 1);


Now our window contains pairwise-coprime elements.

We calculate its length and update the answer.

Remember, even if the current pair is not coprime, a subarray of length 2 is still product equivalent. That's why we initialized ans = 2.
