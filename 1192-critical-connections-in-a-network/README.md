## Explanation

The mental model

Think of DFS creating:

        u
       / \
      ... v
          |
       subtree

Ask:

Can v's subtree somehow reach u or an ancestor of u without using (u,v)?

low[v] answers exactly that.

low[v] <= tin[u]
    → alternate route exists
    → NOT a bridge

low[v] > tin[u]
    → no alternate route
    → BRIDGE
Complexity
Time:  O(V + E)
Space: O(V + E)

For n, edges <= 10^5, this is the intended approach.

The pattern to remember is:

Undirected graph + "edge whose removal disconnects the graph" → think Bridge / Tarjan DFS → low[v] > tin[u].
