## Explanation

You may swap elements at indices i and j only if nums[i] AND nums[j] == k, where AND denotes the bitwise AND operation and k is a non-negative integer.

Return the maximum value of k such that the array can be sorted in non-decreasing order using any number of such swaps. If nums is already sorted, return 0.

That means k cannot have any bit that is missing from even one misplaced element.

Consider Example 1:
nums = [0, 3, 2, 1]


The correct sorted array is [0, 1, 2, 3].
Index i	nums[i]	Correct position?	Action
0	0	Yes	Skip
1	3	No	Initialize k = 3
2	2	Yes	Skip
3	1	No	k = 3 & 1 = 1

The answer is 1.

Why does k = 1 work? The misplaced values are 3 and 1, and:
3 = 11
1 = 01
    --
AND 01 = 1


We can swap them because their AND equals 1:
[0, 3, 2, 1]
       swap
[0, 1, 2, 3]


4. Why is the answer always achievable?
There's one subtle detail: the operation requires the AND to equal k, not merely contain its bits.

Let k be the AND of all misplaced elements. Every misplaced value x contains all the set bits of k, so:
\[
x\ \&\ k=k
\]

Since the array is a permutation of 0 through n-1, the value k itself exists in the array. We can use that value as an intermediate to swap with misplaced values, because each such swap satisfies the rule. These swaps allow us to put the misplaced elements into their correct positions.

Thus, this k is achievable. Any larger k would contain a bit missing from at least one misplaced value, making that value impossible to move. So this is the maximum.

TC: O(n) for the iteration of the entire array that is there.
SC:O(1) No extra space is needed only 3 variables are needed for this.
