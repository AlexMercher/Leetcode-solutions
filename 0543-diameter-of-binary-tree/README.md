## Explanation

The key observation is:

If the longest path passes through a node, then its length is
height(left subtree) + height(right subtree).

So while calculating heights, we can update the maximum diameter.

Example
        1
       / \
      2   3
     / \
    4   5

At node 2:

height(left)  = 1
height(right) = 1

So a path through 2 has:

1 + 1 = 2 edges

At node 1:

height(left)  = 2
height(right) = 1

So a path through 1 has:

2 + 1 = 3

Thus diameter = 3.
