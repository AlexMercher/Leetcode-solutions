## Explanation

1. Find every palindrome of length ≥ k

Let

pal[l][r] = true

when s[l...r] is a palindrome.

The standard recurrence is:

pal[l][r] =
    (s[l] == s[r]) &&
    (r-l <= 2 || pal[l+1][r-1]);

Then only consider it as a usable substring when:

r-l+1 >= k
2. DP on the prefix

Let

dp[i] = maximum number of valid non-overlapping palindromes
        using s[0 ... i-1]

So dp[0] = 0.

At position i, we have two choices:

Don't end a palindrome at i-1:

dp[i] = dp[i-1];

Take a palindrome [j ... i-1]:

dp[i] = max(dp[i], dp[j] + 1);

because everything before j is already handled by dp[j].
