## Explanation

The important difference from permutation
For permutations:
choose any unused element
→ need `used[]`

For subsets:
choose the next element or skip it
→ just move forward with `index`

And this:
ans.push_back(curr);

is done at every recursion call, because every partial selection is already a valid subset.
For [1,2,2], this gives:
[]
[1]
[1,2]
[1,2,2]
[2]
[2,2]

The key mental model is:
Subsets = every node in the recursion tree is an answer. Permutations = only leaves are answers.
