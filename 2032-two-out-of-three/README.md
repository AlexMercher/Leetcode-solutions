## Explanation

The core bitmask idea

For:

nums1 = [1,2,3]

the mask has:

bit 1 = 1
bit 2 = 1
bit 3 = 1

Then for a number x:

mask & (1 << x)

asks:

Is x present in this array?

So for every x:

present in mask1? → +1
present in mask2? → +1
present in mask3? → +1

If count ≥ 2, add it.

One thing to remember about your __int128

Because you're using a bit position potentially larger than 31, don't write:

1 << x

Write:

(__int128)1 << x

Otherwise the shift happens as an int first.
