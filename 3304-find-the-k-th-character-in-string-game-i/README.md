## Explanation

The string starts as:

a

Then:

ab
abbc
abbcbccd
abbcbccdcddcde...

Look at the first 8 positions:

position: 1 2 3 4 5 6 7 8
char:     a b b c b c c d

Now look at k-1 in binary:

k = 4
k-1 = 3 = 011

Number of 1s = 2.

Therefore:

'a' + 2 = 'c'

which is correct.

For k = 5:

k-1 = 4 = 100
popcount = 1

'a' + 1 = 'b'

For k = 10:

k-1 = 9 = 1001
popcount = 2

'a' + 2 = 'c'
