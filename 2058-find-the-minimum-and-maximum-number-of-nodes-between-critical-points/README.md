## Explanation

You only really need the positions of the critical points, but you don't need to store all of them. To get:

minimum distance → only the distance between consecutive critical points
maximum distance → distance between the first and last critical point

So maintain just:

first = first critical point
prev  = previous critical point
minDist = minimum gap seen so far
How to detect a critical point

For a node curr, you need:

prevNode.val < curr.val > nextNode.val

or:

prevNode.val > curr.val < nextNode.val

So keep three pointers:

prev → curr → next

Maintain:

first occurrence
previous occurrence
best minimum gap

Then while scanning:

new position
    ↓
distance from previous
    ↓
update min
    ↓
move previous

And at the end:

last - first

gives the maximum distance.
