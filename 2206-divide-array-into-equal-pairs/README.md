## Explanation

The code is:

bool seen[501] = {};

for (int x : nums) {
    seen[x] = !seen[x];
}

The important part is:

seen[x] = !seen[x];

It means:

Every time I see x, flip its current state.

Initially, because of:

bool seen[501] = {};

all values are:

false

So for one particular number, say x = 2, start with:

seen[2] = false
First time we see 2
seen[2] = !seen[2];

becomes:

false → true

So:

seen[2] = true

At this point, 2 has occurred once, which is odd.

Second time we see 2

Flip it again:

true → false

Now:

seen[2] = false

2 has occurred twice, which is even.

Third time

Flip again:

false → true

Three occurrences → odd.

Fourth time
true → false

Four occurrences → even.

So the pattern is:

number of occurrences    seen[x]

0                         false
1                         true
2                         false
3                         true
4                         false
5                         true
...

Therefore:

seen[x] == true

means:

x has appeared an odd number of times.

And:

seen[x] == false

means:

x has appeared an even number of times.

## My Notes

## mistakes

XOR checks parity bit-by-bit across the values, not parity of occurrences of each value.

For example:

1 ^ 2 ^ 3 = 0

because:

001
010
011
---
000

But that doesn't mean every number has appeared twice.
