## Explanation

So the row contents become:

row 0 → P I N
row 1 → A L S I G
row 2 → Y A H R
row 3 → P I

Then concatenate the rows:

PIN
ALSIG
YAHR
PI

giving:

"PINALSIGYAHRPI"
How dir works

This is the important part:

if (row == 0)
    dir = 1;
else if (row == numRows - 1)
    dir = -1;

row += dir;

dir tells us whether we're moving:

1  → downward
-1 → upward
