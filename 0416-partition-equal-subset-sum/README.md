## Explanation

IF the sum if odd we cannot add the integers to make equal sum so return false then and there only but if it's even then just make it into a knapsack dp where all the states are false and dp[0]=true, because we do dp[j]=dp[j] || dp[j-x] here if either dp[j] or dp[j-x] is reachable and any one of them is true we get true and thus we can ensure that we get true only if we reach dp[0].
