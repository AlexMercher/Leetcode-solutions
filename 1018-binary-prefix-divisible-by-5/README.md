## My Notes

### Mistakes

Once the prefix becomes longer than 32 bits, int ans overflows, and after that:

ans % 5

is no longer the remainder of the actual binary number.

That's why your first wrong result starts appearing around the later bits in the testcase.

Fix it by keeping only the remainder

If the current prefix represents number N, and we append bit x:

new number = N * 2 + x

Therefore modulo 5:

new remainder = (old remainder * 2 + x) % 5
