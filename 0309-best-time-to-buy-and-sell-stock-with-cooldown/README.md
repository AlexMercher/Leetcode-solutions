## Explanation

A clean way to define it:

hold[i] = maximum profit after day i if we are holding a stock
free[i] = maximum profit after day i if we are not holding a stock

When we are not holding a stock, two things can happen:

1. We did nothing today:
   free[i-1]

2. We sold today:
   hold[i-1] + prices[i]

So:

free[i] = max(free[i-1], hold[i-1] + prices[i]);

For hold[i]:

1. Keep holding:
   hold[i-1]

2. Buy today:
   free[i-2] - prices[i]

Why i-2?

Because if we sell on day i-1, then day i is the cooldown, so we cannot buy on day i. Therefore, when buying on day i, the last day we could have been in a "free to buy" state is i-2.

So:

hold[i] = max(hold[i-1], free[i-2] - prices[i]);
