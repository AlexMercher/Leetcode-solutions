## Explanation

# Explanation

1. Find the longest sequential prefix of `nums`.
2. A prefix is sequential when every element is exactly `+1` from the previous one.
3. Start the sum with `nums[0]`, since the prefix always contains it.
4. Continue while:

   ```cpp
   nums[i] == nums[i-1] + 1
   ```
5. Once the sequence breaks, `sum` is the required starting value.
6. Now we need the **smallest missing integer >= sum**.
7. Store all array values in an `unordered_set`.
8. While `sum` exists in the set, increment it.
9. The first value not found is the answer.

```cpp
while(s.count(sum))
    sum++;
```

### Example

```text
nums = [3,4,5,1,12,14,13]

Sequential prefix: [3,4,5]
sum = 12

12 → exists
13 → exists
14 → exists
15 → missing

Answer = 15
```

### Complexity

```text
Time:  O(n) average
Space: O(n)
```
