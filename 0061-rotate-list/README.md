## Explanation

Before:

1 → 2 → 3 → 4 → 5 → NULL
        ↑       ↑
      newTail  newHead

After:

newTail->next = nullptr;

we get:

1 → 2 → 3 → NULL

4 → 5 → NULL

Then:

tail->next = head;

gives:

4 → 5 → 1 → 2 → 3 → NULL
↑
newHead
The general formula

For right rotation by k:

old list:
1 → 2 → 3 → 4 → 5

last k nodes:
            4 → 5
            ↑
        new head

everything before them:
1 → 2 → 3
          ↑
       new tail

So:

new tail position = n - k
new head = newTail->next

And then:

newTail->next = nullptr;
tail->next = head;
return newHead;
