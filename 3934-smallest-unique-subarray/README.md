## Explanation

The brute-force approach would generate all subarrays and compare their contents. That can become very expensive for n = 100000.

We need a better observation.

2. Important observation: Every subarray is a prefix of a suffix
Consider:
nums = [1, 1, 2, 2, 1]


We can consider every possible starting position as a separate suffix:
Starting index	Suffix
0	[1,1,2,2,1]
1	[1,2,2,1]
2	[2,2,1]
3	[2,1]
4	[1]

Every subarray starting at index i is a prefix of the suffix starting at i.

For example, suffix starting at index 1:
[1, 2, 2, 1]


Its possible subarrays are:
[1]
[1, 2]
[1, 2, 2]
[1, 2, 2, 1]


Now our problem becomes:

For each suffix, find the shortest prefix that does not occur as a prefix of any other suffix.

This is where Suffix Arrays become useful.
3. Suffix Array: Arrange all suffixes lexicographically
A Suffix Array stores the starting indices of all suffixes in lexicographical order.

For our example:
nums = [1, 1, 2, 2, 1]


The suffixes are:
Index 0: [1, 1, 2, 2, 1]
Index 1: [1, 2, 2, 1]
Index 2: [2, 2, 1]
Index 3: [2, 1]
Index 4: [1]


After lexicographical sorting:
Suffix Array position	Original index	Suffix
0	4	[1]
1	0	[1,1,2,2,1]
2	1	[1,2,2,1]
3	3	[2,1]
4	2	[2,2,1]

Therefore:
sa = [4, 0, 1, 3, 2];


Why do we need this ordering?

Because suffixes that share a common prefix appear close to each other in lexicographical order.

This allows us to efficiently find duplicate prefixes.
4. LCP (Longest Common Prefix)
LCP tells us how many starting elements two suffixes have in common.

For example:
Suffix A = [1, 2, 3, 4]
Suffix B = [1, 2, 5, 6]


Their common prefix is:
[1, 2]


Therefore:
LCP = 2


For our problem, we need to know:

What is the maximum LCP between a suffix and any other suffix?

Call this value maxLCP.

Suppose a suffix has:
[1, 2, 3, 4]


And its maximum LCP with another suffix is 2.

This means:
Length 1 prefix → Duplicate
Length 2 prefix → Duplicate
Length 3 prefix → Unique


Why is length 3 unique?

Because no other suffix shares the first three elements.

5. Why do we only need the previous and next suffixes?
This is another important observation.

We don't need to calculate the LCP of every suffix against every other suffix.

After sorting suffixes lexicographically, the maximum LCP of a suffix with any other suffix must be achieved by one of its immediate neighbours:
- Previous suffix in the Suffix Array.
- Next suffix in the Suffix Array.
Why?

Suffixes sharing a common prefix are grouped together in lexicographical order. If another suffix shares a prefix of length L, at least one immediate neighbour must share that prefix as well.

6. Calculate the shortest unique subarray
Suppose:
Starting index = i
Maximum LCP = 3


The minimum unique subarray length starting at i is: 3+1=4
However, we must also make sure that the suffix actually contains at least four elements.

Therefore: maxLCP+1<=n-i;
If this condition is satisfied, we consider the candidate answer:
ans = min(ans, maxLCP + 1);


We repeat this for every suffix and return the minimum.
