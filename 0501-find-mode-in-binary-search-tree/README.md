## Explanation

The key observation is:

Inorder traversal of a BST with duplicates gives the values in non-decreasing order.

For example:

        1
         \
          2
         / \
        2   2

Inorder:

1 2 2 2

So all equal values appear consecutively. That means we can simply count the current run of equal values.
