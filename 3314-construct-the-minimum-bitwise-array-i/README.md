## Explanation

How do we get the minimum ans?

Suppose:

nums = 11 = 1011

It has two trailing 1s:

1011
  ^^

The answer is:

9 = 1001

because:

1001
1010
----
1011

Notice that we changed the second-last bit to 0 while keeping everything above it the same.

For:

13 = 1101

there is only one trailing 1:

1101
   ^

So:

ans = 1100 = 12

And:

31 = 11111

has five trailing 1s, so:

ans = 01111 = 15
A very convenient formula

Let:

lowbit = lowest set bit of (nums[i] + 1)

Then:

ans = nums[i] - lowbit / 2;

Examples:

nums = 5
nums+1 = 6 = 110
lowbit = 2

ans = 5 - 1 = 4
nums = 11
nums+1 = 12 = 1100
lowbit = 4

ans = 11 - 2 = 9
nums = 31
nums+1 = 32 = 100000
lowbit = 32

ans = 31 - 16 = 15

We can get the lowest set bit with:

x & -x
