## Explanation

Take:

      1
     / \
    2   3

Start at 1.

Go left → node 2

2 is a leaf.

leftSum  = 0
rightSum = 0

tilt = |0 - 0| = 0

So:

ans = 0

But return:

2 + 0 + 0 = 2

So the parent receives:

leftSum = 2

This is why we cannot return 0 from a leaf.

Go right → node 3

Similarly:

tilt = 0
return 3

So at node 1:

leftSum  = 2
rightSum = 3

Tilt:

|2 - 3| = 1

So:

ans = 1

And return subtree sum:

1 + 2 + 3 = 6

Final answer:

1
