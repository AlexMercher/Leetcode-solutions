## Explanation

Why it works

After sorting:

(0,30), (5,10), (15,20)

Check:

(0,30)
   ↓
(5,10)

Current start:

5

Previous end:

30

Since:

5 < 30

they overlap → false.

For:

(5,8), (9,15)

we get:

5----8
      9---------15

and:

9 < 8  → false

so there is no conflict.

Notice the condition is strictly <:

intervals[i].start < intervals[i-1].end

because:

(0,8), (8,10)

is allowed.

So the mental pattern is:

Sort by start → compare current start with previous end.
