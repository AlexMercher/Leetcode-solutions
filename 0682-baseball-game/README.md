## Explanation

Suppose:

record = [5, 10]

The stack looks like:

top → 10
      5

For:

int first = st.top();
st.pop();

we get:

first = 10

stack:
top → 5

Then:

int second = st.top();

so:

second = 5

The new score is:

10 + 5 = 15

But we must keep the old 10 because the record should become:

[5, 10, 15]

That's why:

st.push(first);
st.push(first + second);
