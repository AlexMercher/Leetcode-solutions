# Regular Expression Matching — Explanation

Use 2D memoized DP.

`dp[i][j]` represents whether `s[i...]` can be matched by `p[j...]`.

For a normal character or `.`:
- If they match, move both pointers:
  `solve(i+1, j+1)`

When `p[j+1] == '*'`, there are two choices:

1. `*` matches zero characters:
   `solve(i, j+2)`

2. `*` consumes one matching character:
   `solve(i+1, j)`

Therefore:

`solve(i,j) = skip || (match && take)`

`dp` is an `int` because we need 3 states:
`-1 = uncomputed`, `0 = false`, `1 = true`.

C++ converts `true → 1` and `false → 0`.

Base case:
When `j == p.size()`, return `i == s.size()`.

Time: O(n × m)
Space: O(n × m)
