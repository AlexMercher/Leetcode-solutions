## Explanation

xample
[1,2,9]

Start from the end:

9 → 0   carry
[1,2,0]

2 → 3
[1,3,0]

Return:

[1,3,0]

For:

[9,9,9]

all digits become 0:

[0,0,0]

Then:

digits.insert(digits.begin(), 1);

gives:

[1,0,0,0]

Complexity:

Time:  O(n)
Space: O(1) extra

The pattern to remember is:

Start from the right, handle 9 as carry, stop at the first digit that isn't 9.
