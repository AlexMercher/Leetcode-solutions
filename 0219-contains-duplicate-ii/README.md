## Explanation

Suppose:

nums = [1, 2, 1, 1]

When we're at the last 1:

indices:  0  1  2  3
          1  2  1  1

There are two previous 1s:

3 - 0 = 3
3 - 2 = 1

The latest occurrence gives the smallest distance.

So storing only:

lastIndex[1] = 2

is enough.

Dry run

Example:

nums = [1,2,3,1]
k = 3
i=0 → 1 not seen → lastIndex[1]=0
i=1 → 2 not seen → lastIndex[2]=1
i=2 → 3 not seen → lastIndex[3]=2
i=3 → 1 seen at 0

3 - 0 = 3 <= k

Therefore:

true
