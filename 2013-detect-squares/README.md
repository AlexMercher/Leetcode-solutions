## Explanation

add [3,10]
add [11,10]
add [11,18]
add [3,18]

Then query:

count([3,10])

The points are:

(3,10) -------- (11,10)
  |                  |
  |                  |
(3,18) -------- (11,18)

This is a square of side 8.

1. What does mp contain?

After the four add() calls:

mp[3]:
    10 -> 1
    18 -> 1

mp[11]:
    10 -> 1
    18 -> 1

Remember:

mp[x][y]

means:

How many copies of point (x,y) have we added?

2. Start count([3,10])
int x = 3;
int y = 10;
int ans = 0;

We iterate:

for(auto &[y2,cnt] : mp[x])

Since:

x = 3

we iterate over:

mp[3]

which contains:

y2 = 10, cnt = 1
y2 = 18, cnt = 1
First iteration
y2 = 10
cnt = 1

We have:

if(y2 == y) continue;

Because:

10 == 10

we skip it.

Why?

Because we need a different y-coordinate to create a positive-height square.

Second iteration

Now:

y2 = 18
cnt = 1

So the point we're using is:

(3,18)

The role of cnt is:

How many copies of (x,y2) exist.

Here:

cnt = 1

because (3,18) was added once.

3. Calculate side length
int d = abs(y2 - y);

So:

d = |18 - 10|
  = 8

That means the square must have side length 8.

4. Check square to the right
int rightX = x + d;

So:

rightX = 3 + 8
       = 11

The two required points are:

(11,10)
(11,18)

Now:

ans += cnt * mp[rightX][y] * mp[rightX][y2];

Substitute:

cnt = 1
mp[11][10] = 1
mp[11][18] = 1

Therefore:

ans += 1 * 1 * 1
     = 1

So:

ans = 1

We've found one square.

5. Check square to the left
int leftX = x - d;

So:

leftX = 3 - 8
      = -5

The required points would be:

(-5,10)
(-5,18)

But neither exists.

Therefore:

mp[-5][10] = 0
mp[-5][18] = 0

Contribution:

1 * 0 * 0 = 0

So:

ans = 1

Final answer:

1
Now the important role of cnt

Suppose instead we did:

add({3,18});
add({3,18});
add({11,10});
add({11,10});
add({11,18});

Now:

mp[3][18] = 2
mp[11][10] = 2
mp[11][18] = 1

When querying:

(3,10)

we get:

y2 = 18
cnt = 2

Why is that important?

Because the two copies of (3,18) are considered different points.

So we have:

2 choices for (3,18)
2 choices for (11,10)
1 choice for (11,18)

Therefore:

2 * 2 * 1 = 4

different ways to choose the three points.

That's exactly why we multiply:

cnt * mp[rightX][y] * mp[rightX][y2]
Think of the multiplication as choices

For a fixed y2:

cnt
  ↓
number of choices for first point

mp[rightX][y]
  ↓
number of choices for second point

mp[rightX][y2]
  ↓
number of choices for third point

So:

total squares from this configuration
=
choices for point 1
×
choices for point 2
×
choices for point 3
