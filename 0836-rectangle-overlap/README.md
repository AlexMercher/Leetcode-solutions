## Explanation

For the x-axis, the overlap interval is:

[max(x1₁, x1₂),  min(x2₁, x2₂)]

So the width of the overlap is:

min(x2₁, x2₂) - max(x1₁, x1₂)

For it to be a positive overlap:

min(x2₁, x2₂) > max(x1₁, x1₂)

Same independently for the y-axis.

about encapsulation

Suppose:

Rect A: x = [0, 10]
Rect B: x = [3, 7]

Here:

min(right ends) = min(10, 7) = 7   ← B
max(left ends)  = max(0, 3) = 3   ← B

Both boundaries of the overlap come from B, meaning B is completely inside A along the x-axis.

Visually:

A: 0 ───────────────────── 10
       ┌─────────────┐
B:     3             7
       └─────────────┘

The same can happen on the y-axis too, in which case one rectangle is fully contained inside the other.
