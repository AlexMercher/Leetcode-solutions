## Explanation

So if:

dp[i]

is the ith ugly number, we can generate candidates like:

dp[x] * 2
dp[x] * 3
dp[x] * 5

The problem is that we need the next smallest unused candidate.

Why three pointers?

Suppose:

dp = [1,2,3,4,5,6,8,9,10,...]

We maintain:

p2 → first ugly number whose ×2 candidate hasn't been used
p3 → first ugly number whose ×3 candidate hasn't been used
p5 → first ugly number whose ×5 candidate hasn't been used

Then:

next ugly = min(
    dp[p2] * 2,
    dp[p3] * 3,
    dp[p5] * 5
)
The interesting part: advancing multiple pointers

Suppose:

dp = [..., 3, ...]

and:

3 * 2 = 6
2 * 3 = 6

When 6 is selected, both pointers must move.

That's why we use:

if(dp[i] == next2) p2++;
if(dp[i] == next3) p3++;
if(dp[i] == next5) p5++;

rather than else if.

This prevents duplicate ugly numbers.
