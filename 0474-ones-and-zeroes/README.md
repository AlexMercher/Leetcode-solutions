## Explanation

So this is essentially:

capacity 1 = m zeros
capacity 2 = n ones
value      = 1 item
1. DP state

Let

dp[i][j]

mean:

Maximum number of strings we can choose using at most i zeros and j ones.

Since each string has a cost:

zeros = number of '0's
ones  = number of '1's

suppose the current string has:

z zeros
o ones

Then we have two choices.

Don't take the string

The answer stays:

dp[i][j]
Take the string

We must have enough capacity:

i >= z && j >= o

After taking it, remaining capacity is:

i-z zeros
j-o ones

So:

dp[i][j] = dp[i-z][j-o] + 1

Therefore:

dp[i][j] = max(dp[i][j], dp[i-z][j-o] + 1);
2. Why do we iterate backwards?

This is the most important detail.

Each string can be used at most once.

Therefore this is 0/1 Knapsack, not unbounded knapsack.

We process capacities:

for (int i = m; i >= z; i--)
    for (int j = n; j >= o; j--)
Why backwards?

Suppose we processed forward:

i = z → m
j = o → n

Then while processing the current string, we could accidentally use a dp state that was already updated using the same string.

That would effectively allow:

use current string
use current string again
use current string again...

which is wrong.

Backward iteration ensures that:

dp[i-z][j-o]

still represents the state before considering the current string.

This is exactly the same reason that ordinary 0/1 subset-sum uses a backward loop.

3. Example

Take:

str = "10"

It contains:

1 zero
1 one

Suppose:

m = 1
n = 1

Before processing it:

dp = 0

At:

i = 1
j = 1

we can take it:

dp[1][1] = max(dp[1][1], dp[0][0] + 1)
         = 1

So:

dp[1][1] = 1

means:

With at most 1 zero and 1 one, we can select 1 string.
