## Explanation

You are only allowed to:

1 → 0

You can never do:

0 → 1

Therefore every 1 bit in k must already be 1 in n.

That condition is:

(n & k) == k
Example
n = 10 = 1010
k = 8  = 1000
1010
1000
----
1000

So:

(n & k) == k

is true.
