## Explanation

Pass 1: Create all the new nodes
We only copy the values and next structure.
Suppose:
A → B → C

We create:
A' → B' → C'

and store:
mp[A] = A'
mp[B] = B'
mp[C] = C'

At this point, the random pointers are not connected yet.
Pass 2: Connect next and random
For an original node cur:
mp[cur]->next = mp[cur->next];
mp[cur]->random = mp[cur->random];

Why does this work?
Because mp tells us exactly which copied node corresponds to every original node.
For example:
cur = A
A.random = C

then:
mp[A]->random = mp[C];

So:
A' → C'

and no pointer in the copied list points back to the original list.
