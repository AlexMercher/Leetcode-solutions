## Explanation

Dry run

For:

        2
       / \
      2   5
     / \
    2   3

At root 2:

left = 2
right = 5

Since left == root->val, search left subtree.

At left 2:

left = 2
right = 3

Again left == root->val, search that subtree. It has no larger value, so:

left = -1
right = 3

returns 3.

Back at the first 2:

left = 3
right = 5

so:

min(3,5) = 3

Back at root:

min(3,5) = 3

Answer = 3.

The important thing is:

If child value == root value:
    that subtree may contain the second minimum deeper down.

If child value > root value:
    that child itself is the smallest candidate from that side.

So equal values force us to keep searching downward.
