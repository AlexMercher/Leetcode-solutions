## Explanation

In grid DFS, mark a cell visited before making recursive calls. Otherwise, neighboring cells can send the recursion straight back to cells that are already being explored.

Count the number of islands that are there and then do ensure that we get the total count that is there and take the best out of it.

## My Notes

### Mistakes

1. You never mark a cell as visited — this causes stack overflow
Inside dfs():
count++;
dfs(grid, r+1, c);
dfs(grid, r-1, c);


Suppose two adjacent cells are both 1:
1 1


Your recursion can go:
dfs(0,0)
   ↓
dfs(0,1)
   ↓
dfs(0,0)
   ↓
dfs(0,1)
   ↓
... forever


That's why your error log reports a stack overflow from repeated recursive calls. Pasted markdown.md

Fix: Mark each land cell as visited before exploring its neighbors:
grid[r][c] = 0;


This prevents DFS from revisiting that cell.
2. Your column count is wrong
You wrote:
n = grid.size();


But grid.size() gives the number of rows, not columns.
Correct:
n = grid[0].size();


Otherwise, rectangular grids will be processed incorrectly.
3. Initialize best to 0
int best = 0;


If the grid contains no land, the maximum island area is 0, not INT_MIN.
