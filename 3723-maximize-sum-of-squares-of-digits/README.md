## Explanation

First, check whether a solution is possible. With num digits, the maximum digit sum is 9*num. If sum exceeds that, return an empty string.
Otherwise, build the number from left to right:
1. Choose digit = min(9, sum).
2. Append that digit to the answer.
3. Subtract it from sum.
4. Repeat until num digits have been filled.
