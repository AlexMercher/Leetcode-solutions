## Explanation

For:

root:
      3
     / \
    4   5
   / \
  1   2

subRoot:
    4
   / \
  1   2

Start at 3:

sameTree(3,4)

Values differ → false.

Then:

isSubtree(4, subRoot)

Now:

4 == 4
1 == 1
2 == 2
all structures match

So sameTree(4, subRoot) returns true.

Therefore the final answer is true.

The important distinction is:

isSubtree()
    ↓
searches for the possible starting node

sameTree()
    ↓
once a candidate is found, verifies the ENTIRE structure
