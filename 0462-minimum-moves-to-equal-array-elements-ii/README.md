## Explanation

This is the easiest approach to implement and understand.
Step 1: Sort the array
sort(nums.begin(), nums.end());


Step 2: Find the median
int n = nums.size();
int median = nums[n / 2];


Why n / 2?
- For odd-sized arrays, it gives the exact middle element.
- For even-sized arrays, it gives the upper middle element.
Remember, either middle value is optimal for an even-sized array.
Step 3: Calculate the operations
For every element, calculate its absolute difference from the median.
long long moves = 0;

for (int x : nums) {
    moves += abs((long long)x - median);
}


We use long long because subtracting two extreme 32-bit integers can overflow an int.
