## Explanation

# Edit Distance — Explanation

Use 2D DP.

`dp[i][j]` = minimum operations needed to convert the first `i` characters of `word1` into the first `j` characters of `word2`.

## Base Cases

If `word2` is empty, we must delete all `i` characters:

```cpp
dp[i][0] = i;

If word1 is empty, we must insert all j characters:

dp[0][j] = j;

Because the table has size (m+1) x (n+1), both loops must use <=.

Transition

If the current characters match:

dp[i][j] = dp[i-1][j-1];

Otherwise, consider three operations:

Insert  → dp[i][j-1]
Delete  → dp[i-1][j]
Replace → dp[i-1][j-1]

Therefore:

dp[i][j] = 1 + min({
    dp[i][j-1],
    dp[i-1][j],
    dp[i-1][j-1]
});

The answer is:

dp[m][n]

Time: O(mn)
Space: O(mn)

## My Notes

# Mistakes

1. Base-case loops must use `<=`, not `<`, because the DP table has `m+1` and `n+1` states.
2. `dp[i][0] = i` represents `i` deletions.
3. `dp[0][j] = j` represents `j` insertions.
4. Equal characters require no operation: `dp[i-1][j-1]`.
5. For different characters, consider insert, delete, and replace.
