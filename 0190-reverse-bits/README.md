## Explanation

For example:

input:  00000010100101000001111010011100
output: 00111001011110000010100101000000

The cleanest way is to process one bit at a time.

The idea

We build the answer from left to right.

For each of the 32 bits:

Get the last bit of n using:

n & 1
Shift the answer left by 1 to make space.
Put that extracted bit into the answer.
Shift n right by 1 to process the next bit.

So:

result = (result << 1) | (n & 1);
n >>= 1;

Repeat exactly 32 times.
