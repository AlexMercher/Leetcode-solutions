## Explanation

# Stone Game V — Explanation

Use interval DP: `dp[l][r]` = maximum score from `l..r`.
Try every split `k`.
Use prefix sums to calculate both sides in O(1).
Bob discards the larger side, so Alice gains the smaller side.
If equal, Alice chooses the better side.
Base case: one stone → 0.

Time: O(n³), Space: O(n²).

## My Notes

# Mistakes

1. Don't split only at the middle; every partition is possible.
2. Don't copy left/right vectors; use indices `[l,r]`.
3. Don't repeatedly calculate sums; use prefix sums.
4. Memoize overlapping interval states.
5. Equal sums require Alice to choose the better surviving side.
