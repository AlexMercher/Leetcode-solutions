## Explanation

For:
        6
       / \
      2   8
     / \ / \
    0  4 7 9
      / \
     3   5

p = 2, q = 8
At 6:
2 < 6
8 > 6

They're on different sides → 6 is the LCA.
p = 2, q = 4
At 6:
2 < 6
4 < 6

Both left → go to 2.
At 2:
p == 2
q > 2

Now they split (and p itself is allowed to be the ancestor), so return 2.
The pattern
The important thing to recognize is:
BST + LCA → don't search for both nodes separately. Use their values to decide which subtree can contain the answer.

Because each step cuts the search space roughly in half, the complexity is:
Time:  O(h)
Space: O(1)

For a balanced BST, h = O(log n).
