## Explanation

For the sequence:

100,80,60,70,60,75

at 75:

stack before:
(100,1)
(80,1)
(70,2)
(60,1)

75:
pop (60,1) → span=2
pop (70,2) → span=4
80 > 75 → stop

So answer is 4.

The important point is that the stack contains compressed blocks, not just individual days.

Pattern
Need nearest previous greater price
        ↓
Monotonic decreasing stack
        ↓
Store (price, span)
        ↓
When current price >= top:
    absorb top's whole span
