## Explanation

The standard one-pass solution is the fast/slow pointer technique.

The idea is to maintain a gap of exactly n nodes between two pointers.

Why this works

Suppose:

1 → 2 → 3 → 4 → 5 → NULL

and:

n = 2

We want to remove 4.

Use:

fast
slow

First move fast ahead by n nodes:

1 → 2 → 3 → 4 → 5
↑
slow

            ↑
           fast

Now move both together until fast reaches nullptr.

At that point:

1 → 2 → 3 → 4 → 5 → NULL
        ↑
       slow

slow is sitting just before the node we need to remove.

So:

slow->next = slow->next->next;

gives:

1 → 2 → 3 → 5 → NULL
The head edge case

What if:

head = [1]
n = 1

Then the node to remove is the head itself.

The cleanest solution is to use a dummy node before head.

dummy → 1 → 2 → 3 → ...

This makes deleting the head exactly the same as deleting any other node.
