## Explanation

Example
head = 1 → 4 → 3 → 2 → 5 → 2
x = 3

As we traverse:

less:     1 → 2 → 2

greater:  4 → 3 → 5

Then:

less->next = greaterDummy.next;

joins them:

1 → 2 → 2 → 4 → 3 → 5
Why do we need the dummy nodes?

Without dummy nodes, adding the first element to each partition requires special handling.

With:

ListNode lessDummy(0);
ListNode greaterDummy(0);

we always append in exactly the same way:

less->next = head;
less = less->next;

At the end:

less->next = greaterDummy.next;

connects the two partitions.

Very important line
greater->next = nullptr;

Without this, the last node of the >= x partition may still point to some old node from the original list, potentially creating an incorrect chain or cycle.
