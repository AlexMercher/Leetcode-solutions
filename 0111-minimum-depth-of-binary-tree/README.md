## Explanation

For:

    1
   /
  2
 /
3

At 3:

left = nullptr
right = nullptr

so:

depth = 1

At 2:

right = nullptr

so:

depth = 1 + depth(3)
      = 2

At 1:

right = nullptr

so:

depth = 1 + depth(2)
      = 3

Answer = 3.

The biggest thing to remember is:

For minimum depth, nullptr is not automatically depth 0 inside a min(), because that would incorrectly choose a missing branch.
