## Explanation

If alternating bits are there then left right shift produces a number which is all 1's now if we do x&x+1 then it would become 0 thus confirming the the number had alternating bits.
Another way to solve this quetsion:

class Solution {
public:
    bool hasAlternatingBits(int n) {
        while (n > 1) {
            if ((n & 1) == ((n >> 1) & 1))
                return false;
            n >>= 1;
        }
        return true;
    }
};
Keep cheecking for the alternating bits if anywhere they don't alternate return false.
