## Explanation

So the general recursive template is:

if(root == nullptr) return 0;

answer = 0;

for(each child)
    answer = max(answer, solve(child));

return answer + 1;

Time is O(n) because every node is visited once, and recursive space is O(h) where h is the tree height.
