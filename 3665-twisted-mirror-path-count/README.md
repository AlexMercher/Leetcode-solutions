## Explanation

1. Dynamic Programming on a Directed Acyclic Graph (DAG)

Our robot never moves up or left. Therefore, every transition moves towards increasing row or column indices.

There are no cycles, so we can process the cells in topological order using a simple nested loop.

2. Direction-dependent DP states

Sometimes knowing the number of ways to reach a cell is not enough.

The direction from which we reached the cell can affect what happens next.

This is why we initially maintained two states:
DP=(waysfromleft,waysfromtop)
A mirror exchanges the outgoing directions of the two incoming flows.
