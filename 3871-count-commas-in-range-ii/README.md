## Explanation

Start:

x = 1000

Add:

n - 1000 + 1

because every number from 1000 to n has at least one comma.

Then:

x = 1,000,000

Add:

n - 1,000,000 + 1

because every number from 1,000,000 onward has a second comma.

Then:

x = 1,000,000,000

and so on.

So this automatically counts:

1st comma → numbers >= 1,000
2nd comma → numbers >= 1,000,000
3rd comma → numbers >= 1,000,000,000
...
