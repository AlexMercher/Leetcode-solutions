## Explanation

For an opening bracket, that bracket itself creates a new nesting level, so you must increment first:

if(c == '(') {
    depth++;
    ans.push_back(depth % 2);
}

For a closing bracket, the bracket is closing the current nesting level, so you assign it to the same group as its matching ( before decreasing the depth:

else {
    ans.push_back(depth % 2);
    depth--;
}
Example: (( ))

Let's number the depths:

(    → depth becomes 1
(    → depth becomes 2
)    → still belongs to depth 2
)    → still belongs to depth 1

So:

char    action                    depth used for group
(       depth++ → 1               1
(       depth++ → 2               0
)       use depth 2, then --       0
)       use depth 1, then --       1

Result:

[1,0,0,1]

The crucial point is that the opening and closing parentheses of the same pair must receive the same group.

For the pair:

( ... )

the ( enters depth d, and the ) exits depth d.

So:

'(' → increase first, then assign
')' → assign first, then decrease

That's why the order is opposite.
