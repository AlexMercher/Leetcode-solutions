## Explanation

Therefore, we can think of our original operation as:
Instead of incrementing n - 1 elements, decrement exactly one element by 1.

This completely changes how we approach the problem.

1. Find the minimum element
int target = *min_element(nums.begin(), nums.end());


min_element() returns an iterator pointing to the smallest element.

The * dereferences that iterator to obtain its actual value.

2. Calculate the required moves
long long moves = 0;

for (int x : nums)
    moves += (x - target);


Each element needs to be reduced to the minimum value.

For example:
nums = [1, 2, 3]
target = 1

Element 1 → 0 moves
Element 2 → 1 move
Element 3 → 2 moves

Total = 3


3. Return the answer
return (int)moves;


We use long long for the accumulated moves to avoid integer overflow. The problem guarantees that the final answer fits in a 32-bit integer, so casting is safe.
