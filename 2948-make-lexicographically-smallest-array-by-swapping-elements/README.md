## Explanation

The important conceptual trick

Do not think:

"Can I directly swap these two positions?"

Instead think:

"Can these two values reach each other through a chain of valid swaps?"

For example:

a -- b -- c -- d

If:

|a-b| <= limit
|b-c| <= limit
|c-d| <= limit

then all four values form one connected component and can be rearranged among the positions belonging to that component.

That's why this is a DSU / connected-components problem disguised as a swapping problem.

Recognition pattern

When you see:

swap allowed if condition holds
+
you may perform swaps any number of times
+
want lexicographically smallest arrangement

think:

Allowed swaps
      ↓
Can swaps connect elements indirectly?
      ↓
Connected components
      ↓
DSU / graph components
      ↓
Inside each component:
    sort positions
    sort values
    pair smallest with smallest

The especially important observation here is that the condition depends only on the values, so sorting the values lets us find components efficiently.
