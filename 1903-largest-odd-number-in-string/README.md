## Mistakes

For a string:

string num = "35427";

the indices are:

 character:   3   5   4   2   7
 index:       0   1   2   3   4

So:

num[0] = '3'
num[1] = '5'
num[2] = '4'
num[3] = '2'
num[4] = '7'
