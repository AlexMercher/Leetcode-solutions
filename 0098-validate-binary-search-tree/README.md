## Explanation

For your example:

    2
   / \
  2   2

At the root:

allowed: (-∞, +∞)

For the left child:

allowed: (-∞, 2)

but its value is 2:

2 < 2 ❌

so immediately false.

The key lesson is:

A BST property is global, not just parent vs child. Each node must satisfy all the restrictions inherited from its ancestors.

---

## My Notes

For a valid Binary Search Tree (BST), the rule is stronger:

every node in the left subtree must be < root->val
every node in the right subtree must be > root->val

Your code checks only:

root->left->val > root->val
root->right->val < root->val

That misses violations deeper in the subtree.

Your example
    2
   / \
  2   2

Your checks use:

left->val > root->val
2 > 2   // false

right->val < root->val
2 < 2   // false

So you return true.

But BST requires strict inequality, so 2 cannot appear as either child of 2.
