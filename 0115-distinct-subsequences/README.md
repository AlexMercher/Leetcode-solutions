## Explanation

Either we choose the character or we don't choose the character if we have the liberty to handle that thus we can use dp here and make sure that the ways of dp[i][j] => the number of ways to match s till 'i' with t till 'j' hence dp[i][0]=1 as an empty substring is always possible.
1. The DP state

Let

dp[i][j]

mean:

Number of distinct subsequences of the first i characters of s that equal the first j characters of t.

So:

s = "rabbbit"
t = "rabbit"

dp[4][2]

would mean:

How many ways can the first 4 characters of s form the first 2 characters of t?

2. The important choice

Suppose:

s[i-1] == t[j-1]

Then we have two choices for this matching character in s:

Choice 1: Use s[i-1]

Then we need to form the previous part of t:

dp[i-1][j-1]
Choice 2: Don't use s[i-1]

We simply ignore this character of s and try to form all of t:

dp[i-1][j]

Therefore:

dp[i][j] = dp[i-1][j-1] + dp[i-1][j]
What if the characters don't match?

If:

s[i-1] != t[j-1]

then we cannot use s[i-1] to match t[j-1].

So we must skip it:

dp[i][j] = dp[i-1][j]
3. Base cases

This is where n+1 indexing becomes important.

t is empty

There is exactly one subsequence of any string that produces an empty string:

Choose nothing.

Therefore:

dp[i][0] = 1

for every i.

For example:

s = "abc"

"" can be formed in exactly 1 way:
choose nothing
s is empty but t is not

You cannot form a non-empty string from nothing:

dp[0][j] = 0    for j > 0
4. Why dp is (n+1) x (m+1)

Let:

n = s.length();
m = t.length();

We need states for:

0 ... n
0 ... m

because 0 represents taking an empty prefix.

So:

vector<vector<long long>> dp(n + 1, vector<long long>(m + 1));
5. Example: "rabbbit" → "rabbit"

The interesting part is the repeated b.

s = r a b b b i t
t = r a b   b i t

There are three different ways to choose which b to skip/use among the three consecutive bs, producing:

rabbbit
 ^^^

The DP counts these possibilities automatically.
