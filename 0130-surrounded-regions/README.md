## Explanation

Think about the problem in reverse:
Instead of finding all surrounded regions, find all 'O' cells that cannot be captured.
Why? Any 'O' connected to a border 'O' is safe.
1. Run DFS from every border 'O'.
2. Temporarily mark every reachable 'O' as '#'.
3. Change remaining 'O' cells to 'X'.
4. Restore '#' cells to 'O'.
