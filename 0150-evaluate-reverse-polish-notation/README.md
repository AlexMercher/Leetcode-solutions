## Explanation

For Reverse Polish Notation, the whole solution is based on one simple idea:

Numbers are operands, so push them onto the stack. An operator means “take the last two numbers, perform the operation, and push the result back.”

For example:

tokens = ["2","1","+","3","*"]

Process from left to right:

"2" → push 2        stack: [2]
"1" → push 1        stack: [2,1]
"+" → 2 + 1 = 3     stack: [3]
"3" → push 3        stack: [3,3]
"*" → 3 * 3 = 9     stack: [9]

So the answer is 9.

Why a stack?

Because when an operator appears, it always applies to the two most recently available operands.

For:

["4","13","5","/","+"]

we get:

4       → [4]
13      → [4,13]
5       → [4,13,5]

/       → take 13 and 5
          13 / 5 = 2
          [4,2]

+       → take 4 and 2
          4 + 2 = 6
          [6]

So the stack naturally matches the structure of RPN.
