## Explanation

For the 1D bottom-up version, the transition is:

dp[j] = triangle[i][j] + min(dp[j], dp[j + 1]);

not dp[j-1].

Why?

Before processing row i:

dp[j]     = minimum path sum from the cell below at (i+1, j)
dp[j + 1] = minimum path sum from the cell below at (i+1, j+1)

So visually:

        triangle[i][j]
          /       \
      dp[j]      dp[j+1]

We choose the cheaper child:

triangle[i][j] + min(dp[j], dp[j + 1])

Then we overwrite dp[j].

Why is overwriting safe?

Because dp[j] now represents:

the minimum path sum from the current cell down to the bottom.

When we move to the row above, that value is exactly what the upper cell needs.

So the information flows upward:

last row
   ↓
minimum cost for row above
   ↓
minimum cost for row above that
   ↓
...
   ↓
root

That's why by the time we reach:

dp[0]

it contains the minimum path sum from the root to the bottom.
