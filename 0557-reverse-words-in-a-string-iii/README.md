## Explanation

Dry run
s = "Let's take LeetCode contest"

stringstream gives us:

"Let's"
"take"
"LeetCode"
"contest"

First:

Let's → s'teL

Then:

take → ekat

Then:

LeetCode → edoCteeL

Then:

contest → tsetnoc

So:

ans = "s'teL ekat edoCteeL tsetnoc"
Why stringstream?

This:

stringstream ss(s);

lets you treat the string like a stream of words.

Then:

while (ss >> word)

automatically extracts the next word, skipping the spaces.

For this problem, that's much cleaner than manually searching for spaces.
