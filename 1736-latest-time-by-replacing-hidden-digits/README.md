## Explanation

Rules for each position

For:

hh:mm
↑ ↑ ↑ ↑
0 1 3 4
Hour tens time[0]
If it is ? and time[1] <= '3' (or time[1] == '?'), choose 2.
Otherwise choose 1.

But if the second hour digit is fixed to something greater than 3, then the first digit cannot be 2.

A simpler approach is to just try the maximum valid digit for each position based on what is already known.
