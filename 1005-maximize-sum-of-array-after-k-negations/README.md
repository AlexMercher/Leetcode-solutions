## Explanation

If x < 0, flipping it gives |x| and increases the sum.
If x > 0, flipping it makes it negative and decreases the sum.
Therefore, whenever we have useful negative numbers, flip those first.

Example:

nums = [-3,-1,5]

Flip -3:

[3,-1,5]

Flip -1:

[3,1,5]

Those are clearly beneficial.

What about remaining flips?

Suppose there are no negatives left, but we still have to perform flips.

Because performing the same index twice cancels:

x → -x → x

So only the parity of the remaining number of flips matters.

Even remaining flips → answer unchanged.
Odd remaining flips → we must flip one number.

Which number should we flip?

Suppose:

[2,5,7]

Flipping 2 loses:

 2+(-2)=-4 

while flipping 7 loses:

 7+(-7)=-14 

So we should flip the smallest absolute value.
