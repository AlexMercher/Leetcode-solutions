## Explanation

The loop starts at i = 1 because the first point is already where you begin. There is no travel time before visiting it.
Each iteration calculates the minimum time to travel from the previous point to the current point, then adds that time to path.
4. Final complexity
- Time: O(n), because we visit each point once.
- Extra space: O(1), because we use only a few variables.
