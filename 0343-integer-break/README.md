## Explanation

The key idea: use as many 3s as possible

We want to maximize:

a × b × c × ...

subject to:

a + b + c + ... = n

where every part is positive.

The important observations are:

1. Never use a number >= 5 as a single part

Suppose you have 5:

5 → 2 + 3

Product changes from:

5

to:

2 × 3 = 6

So splitting a large number improves the product.

Similarly:

6 → 3 + 3
6 < 9

Therefore, in an optimal solution, we keep breaking numbers down into smaller pieces.

2. 3 is the most useful number

Compare:

3 × 3 = 9

whereas:

2 × 2 × 2 = 8

So three 3s are better than three 2s.

Also:

4 = 2 + 2

but:

2 × 2 = 4

so 4 can be kept as 4 or represented as two 2s with the same product.

The final optimal strategy turns out to be:

Use as many 3s as possible

but there are two exceptions.

When remainder is 1

Suppose:

n % 3 = 1

Don't leave a 1:

3 + 1

because:

3 × 1 = 3

Instead:

4 = 2 + 2

and:

2 × 2 = 4

So replace one 3 + 1 with:

2 + 2
When remainder is 2

Just keep the 2.

So:

n % 3 == 0
→ all 3s

n % 3 == 1
→ remove one 3, use 4 instead

n % 3 == 2
→ all 3s + one 2
