## Explanation

What each part is doing
vector<vector<int>> adj(n);

Creates one list for every vertex.

adj[0] → neighbours of 0
adj[1] → neighbours of 1
...

Then:

adj[u].push_back(v);
adj[v].push_back(u);

because the edge works in both directions.

Then:

visited[next]

prevents us from walking around in cycles forever.

For example:

0 → 1 → 2 → 0

Without visited, we could keep doing:

0 → 1 → 2 → 0 → 1 → 2 → ...
The traversal pattern
edges
 ↓
adjacency list
 ↓
start at source
 ↓
put source in queue
 ↓
take one vertex
 ↓
visit all its unvisited neighbours
 ↓
repeat
 ↓
destination found → true
queue empty → false

And because n and edges.length can both be up to 2 * 10^5, BFS is appropriate:

Time  = O(n + edges)
Space = O(n + edges)
