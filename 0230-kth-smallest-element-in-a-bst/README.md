## Explanation

For a BST:
left < root < right

So inorder:
left → root → right

produces:
smallest → ... → largest

For:
        3
       / \
      1   4
       \
        2

inorder visits:
1 → 2 → 3 → 4

Therefore, when:
k == 0

the current node is exactly the kth smallest.
Complexity
Time:  O(h + k)
Space: O(h)

where h is the tree height.
