## Explanation

For k > 0, for every i we need:

code[i+1], code[i+2], ..., code[i+k]

For example:

code = [5,7,1,4]
k = 3

For i = 0:

7 + 1 + 4 = 12

For i = 1:

1 + 4 + 5 = 10

For i = 2:

4 + 5 + 7 = 16

For i = 3:

5 + 7 + 1 = 13

Instead of recalculating each sum, we slide the window.

For i = 0:

[7, 1, 4]
sum = 12

Move to i = 1:

remove 7
add 5

[1,4,5]
sum = 10

Move again:

remove 1
add 7

[4,5,7]
sum = 16

The % n handles the circular wrapping.

For negative k, we do the exact same idea but move the window in the opposite direction.
