## Explanation

If given index i,j has 1 in its up, adjacent(left) and its left diagnoal then its possible to make a square out of it so the dp becomes the 1+min(dp[i-1][j-1],dp[i][j-1],dp[i-1][j]) with this we can find the exact number of the best possible and then we return the best*best to ensure that we get the total.
