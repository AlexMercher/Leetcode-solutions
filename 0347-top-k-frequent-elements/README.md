## Explanation

Take:

nums = [1,1,1,2,2,3]
k = 2

First count frequencies:

1 → 3
2 → 2
3 → 1

Now create buckets indexed by frequency:

bucket[1] = [3]
bucket[2] = [2]
bucket[3] = [1]

Visual:

frequency
   3 → [1]
   2 → [2]
   1 → [3]
   0 → []

Now start from the highest frequency:

bucket[6] → empty
bucket[5] → empty
bucket[4] → empty
bucket[3] → [1]   → take 1
bucket[2] → [2]   → take 2

We have k = 2, so stop.

Result:

[1,2]
Why this is better than sorting

The important observation is that frequency itself has a bounded range.

For n elements:

frequency can only be:

1, 2, 3, ..., n

So instead of sorting:

3, 2, 1

we directly place each number into:

bucket[frequency]

Then scan the buckets backwards.
