## Explanation

Iteration 1
sum = numbers[left] + numbers[right];

So:

sum = numbers[0] + numbers[3]
    = 2 + 15
    = 17

We need 9.

17 > 9

So we need a smaller sum.

Because the array is sorted, move right left:

right--;

Now:

numbers = [2, 7, 11, 15]
           ↑    ↑
         left  right
          0      2
Iteration 2
sum = numbers[0] + numbers[2]
    = 2 + 11
    = 13

Again:

13 > 9

Need a smaller sum, so:

right--;

Now:

numbers = [2, 7, 11, 15]
           ↑  ↑
         left right
          0    1
Iteration 3
sum = numbers[0] + numbers[1]
    = 2 + 7
    = 9

Now:

9 == target

So:

return {left, right};

returns:

{0, 1}

For LeetCode Two Sum II, because they want 1-based indices, you'd return:

return {left + 1, right + 1};

giving:

[1, 2]
The movement rule

Think of the two pointers as controlling the sum:

sum too small → increase sum → left++

sum too large → decrease sum → right--

For this example:

(2,15) = 17   too big → right--
(2,11) = 13   too big → right--
(2,7)  = 9    exact → found
