## Explanation

So Node is an implementation detail. The outside world only sees the public interface:

LRUCache(...)
get(...)
put(...)

This is actually a good example of encapsulation: hide the machinery, expose only what the data structure needs users to call.

When you see a requirement like:

"Find something in O(1), but also maintain an ordering and remove the oldest/least-used item in O(1)"

think:

HashMap + Doubly Linked List

The hashmap answers:

Where is this key?

The linked list answers:

What is the usage order?

And together:

get      → O(1) average
put      → O(1) average
eviction → O(1)

This is one of the most important data-structure combinations to recognize in interviews.
