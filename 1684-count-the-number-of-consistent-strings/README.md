## Explanation

The key idea is:

Represent the set of allowed characters using the 26 bits of an integer.

Since there are only lowercase English letters:

'a' → bit 0
'b' → bit 1
'c' → bit 2
...
'z' → bit 25
1. Build the mask for allowed

Start:

int mask = 0;

For every character:

mask |= (1 << (c - 'a'));

For:

allowed = "ab"

we get:

a → bit 0 → 000...0001
b → bit 1 → 000...0010

so:

mask = 000...0011
2. Check every character of every word

For a character c in a word, create its bit:

int bit = 1 << (c - 'a');

Then check:

if ((mask & bit) == 0)

If this is 0, that character is not allowed.

If it's non-zero, the character exists in allowed.

Example
allowed = "ab"
mask    = 0011

word = "aaab"

Every character gives either:

a → 0001
b → 0010

and:

0011 & 0001 = 0001  → allowed
0011 & 0010 = 0010  → allowed

So the word is consistent.

For:

word = "ad"

d is:

1 << 3 = 1000

and:

0011
1000
----
0000

So d is not allowed → reject the word.
