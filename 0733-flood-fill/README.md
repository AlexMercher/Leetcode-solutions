## Explanation

Take:

image =
[
 [1,1,0],
 [1,0,0],
 [1,1,1]
]

sr = 0, sc = 0
color = 2

We start at:

(0,0) = 1

So:

int type = image[sr][sc];

gives:

type = 1

We want to change the connected 1s to 2.

Step 1

Queue:

[(0,0)]

We immediately color the starting cell:

[
 [2,1,0],
 [1,0,0],
 [1,1,1]
]

Pop (0,0).

Its 4 neighbors are:

down  → (1,0) = 1 ✅
up    → (-1,0) outside
right → (0,1) = 1 ✅
left  → (0,-1) outside

So we color and push (1,0) and (0,1):

queue = [(1,0), (0,1)]

Grid:

[
 [2,2,0],
 [2,0,0],
 [1,1,1]
]
Step 2

Pop:

(1,0)

Check its 4 neighbors:

down  → (2,0) = 1 ✅
up    → (0,0) = 2 ❌
right → (1,1) = 0 ❌
left  → outside

So color (2,0) and push it:

queue = [(0,1), (2,0)]

Grid:

[
 [2,2,0],
 [2,0,0],
 [2,1,1]
]
Step 3

Pop:

(0,1)

Neighbors:

down  → (1,1) = 0
up    → outside
right → (0,2) = 0
left  → (0,0) = 2

Nothing to add.

Step 4

Pop:

(2,0)

Neighbors:

right → (2,1) = 1 ✅
up    → (1,0) = 2
down  → outside
left  → outside

So color (2,1) and push it.

queue = [(2,1)]

Grid:

[
 [2,2,0],
 [2,0,0],
 [2,2,1]
]
Step 5

Pop (2,1).

Its neighbors:

right → (2,2) = 1 ✅
left  → (2,0) = 2
up    → (1,1) = 0
down  → outside

So:

(2,2) → 2

Queue:

[(2,2)]
Step 6

Pop (2,2).

All its neighbors are either 0, 2, or outside.

Queue becomes empty.

Final grid:

[
 [2,2,0],
 [2,0,0],
 [2,2,2]
]
What the BFS is really doing

The important sequence is:

start
 ↓
color it immediately
 ↓
look at 4 neighbors
 ↓
if neighbor has ORIGINAL color:
    color it
    put it in queue
 ↓
process that neighbor
 ↓
repeat

The reason we color a cell when we push it, rather than when we pop it, is that this prevents the same cell from being added to the queue multiple times.

And the 4-direction arrays:

int dr[] = {1,-1,0,0};
int dc[] = {0,0,1,-1};

represent:

down
up
right
left

So:

rn = row + dr[d];
cn = col + dc[d];

gives each neighboring cell.

The whole thing is just BFS over the connected component of cells having the original color.
