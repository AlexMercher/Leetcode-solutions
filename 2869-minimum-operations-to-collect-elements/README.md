## Explanation

Build a final mask and the mask of the numbers that are used. 
For k = 3, you want to know whether you've collected:

1, 2, 3

You create:

111

using build(3).

Then for every collected value x, you set:

mask |= (1 << x);

So:

collect 1 → 0010
collect 2 → 0110
collect 3 → 1110
