## Explanation

How it works
ListNode ans;
ListNode* temp = &ans;

ans is just a dummy starting node. The actual merged list starts at ans.next.

Then while both lists still have nodes:

if(list1->val >= list2->val)

Take the smaller value and append a new node:

temp->next = new ListNode(list2->val);
temp = temp->next;
list2 = list2->next;

The same happens for list1.

When one list becomes empty, the other list is already sorted, so you simply attach the remainder:

if(list1) temp->next = list1;
if(list2) temp->next = list2;

Finally:

return ans.next;

because ans itself is only the dummy node.
