## Explanation

Dry run: "yyyzz", k = 1

Frequencies:

y = 3
z = 2

Sorted:

0 0 ... 2 3
count = 2
k = 1
diff = 1

Find first positive:

2

Delete it:

ans = 2
diff = 0

Stop.

Answer:

2

The clean mental rule is:

diff = count - k tells you how many distinct characters must be completely deleted. Since deleting a character costs its frequency, delete the diff smallest positive frequencies.
