## Explanation

Suppose:

seats    = [1, 3, 5]
students = [2, 4, 7]

Sort both:

seats    = [1, 3, 5]
students = [2, 4, 7]

Match:

2 → 1  cost = 1
4 → 3  cost = 1
7 → 5  cost = 2

Total:

4

The reason is that matching the smallest student to the smallest seat, second-smallest to second-smallest, etc. avoids unnecessary crossing.

For example, if you had:

students = [2, 7]
seats    = [3, 5]

matching in order:

2 → 3 = 1
7 → 5 = 2
total = 3

while crossing them:

2 → 5 = 3
7 → 3 = 4
total = 7

So sorted-to-sorted is optimal.
