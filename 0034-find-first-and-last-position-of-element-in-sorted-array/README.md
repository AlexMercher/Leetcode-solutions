## Explanation

Use two binary searches instead of one. The first binary search finds the leftmost (first) occurrence by continuing the search on the left after finding the target. The second finds the rightmost (last) occurrence by continuing on the right. Store the current index whenever the target is found and keep searching for a better boundary. This gives an O(log n) solution.

# Mistakes
Returning immediately after finding the target.
Updating the wrong pointer:
First occurrence → high = mid - 1
Last occurrence → low = mid + 1
Using linear expansion after binary search, resulting in O(n) time.
