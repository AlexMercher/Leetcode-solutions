## Explanation

Example
nums = [1,1,4,2,3]
x = 5

Total:

11

We need a middle subarray with:

11 - 5 = 6

Longest such subarray:

[1, 1, 4]

length = 3.

So:

operations = 5 - 3 = 2 Exactly.

Dry run
nums = [1,1,4,2,3]
x = 5
target = 11 - 5 = 6

Start:

left = 0
sum = 0
maxLen = -1

right = 0:

[1]
sum = 1

right = 1:

[1,1]
sum = 2

right = 2:

[1,1,4]
sum = 6

Found target:

length = 3
maxLen = 3

right = 3:

sum = 8

Too large, so shrink:

remove nums[left] = 1

sum = 7
left = 1

Still too large:

remove nums[1] = 1

sum = 6
left = 2

Current window:

[4,2]

length 2.

Then right = 4:

sum = 9

Shrink:

remove 4 → sum = 5

No target.

So:

maxLen = 3

and:

answer = 5 - 3 = 2
Why this transformation is useful

The original problem sounds like:

remove from left/right
remove from left/right
remove from left/right
...

which suggests trying many combinations.

Instead think:

removed sum = x
        ↓
remaining sum = total - x
        ↓
remaining elements must be contiguous
        ↓
find longest contiguous subarray with that sum

That turns the problem into a familiar longest subarray with target sum problem.
