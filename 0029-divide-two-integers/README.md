## Explanation

# Explanation

Instead of repeatedly subtracting the divisor (which is too slow), repeatedly subtract the **largest power-of-two multiple** of the divisor that does not exceed the dividend. This multiple is found efficiently using left bit shifts (`<<`). Each subtraction contributes the corresponding power of two to the quotient. Repeat until the remaining dividend is smaller than the divisor. Handle the sign separately using XOR, and check the special overflow case `INT_MIN / -1`, which must return `INT_MAX`.

## Mistakes

* Using repeated subtraction (`O(dividend/divisor)`), which causes TLE.
* Calling `abs(INT_MIN)`, which overflows.
* Forgetting the overflow case `INT_MIN / -1`.
* Incorrect sign handling.
* Using `>` instead of `>=` when comparing the dividend and divisor.
