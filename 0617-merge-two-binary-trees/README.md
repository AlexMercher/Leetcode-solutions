## Explanation

For:

root1:        1
             / \
            3   2
           /
          5

root2:        2
             / \
            1   3
             \   \
              4   7

At the roots:

1 + 2 = 3

Left children:

3 + 1 = 4

Right children:

2 + 3 = 5

Now go deeper.

For the left side:

5 + nullptr

so keep 5.

For the right subtree of 1:

nullptr + 4

so use 4.

And similarly the 7 is kept.

Result:

        3
       / \
      4   5
     / \   \
    5   4   7
The recursion pattern

This is the useful pattern to remember:

merge(a, b)

if a is null → return b
if b is null → return a

combine a and b
merge left children
merge right children

return merged node

The nice part is that you don't need to separately build a new node every time. root1 itself becomes the merged tree.

Time: O(n) where n is the number of nodes you visit.
Space: O(h) for recursion, where h is the tree height.
