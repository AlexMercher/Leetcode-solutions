## Explanation

Small dry run

Suppose:

      1
     / \
    1   1
       /
      2

Call:

is(root, 1)

Traversal:

left 1  → 1 == 1 ✅
root 1 → 1 == 1 ✅
right 1 → 1 == 1 ✅
its left 2 → 2 != 1 ❌

At 2:

isvalid = false;
return;

So finally:

return isvalid;

gives:

false
If all values are the same
      1
     / \
    1   1

Every node satisfies:

root->val == val

so isvalid remains true.

answer = true

The important idea is simply:

root's value
      ↓
expected value for every node
      ↓
traverse entire tree
      ↓
if any node differs → false
