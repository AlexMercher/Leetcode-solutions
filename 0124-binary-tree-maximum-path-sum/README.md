## Explanation

At node 1:
left = 2
right = 3

so:
best = 2 + 1 + 3 = 6

and then the return value is:
1 + max(2,3) = 4

Why return 4?
Because if node 1 had a parent, the parent could connect to:
3 → 1

or:
2 → 1

but not both, because then you'd create a branching path.
So your intuition was correct:
A path can absolutely use both left and right at a node.

The important distinction is:
GLOBAL ANSWER at node:
left + node + right       both sides

RETURN VALUE to parent:
node + max(left, right)     one side
