## Explanation

Dry run

For:

[0,1,0,3,12]

Start:

pos = 0

i = 0 → 0, ignore.

i = 1 → 1:

nums[pos] = nums[i]
nums[0] = 1

[1,1,0,3,12]
pos = 1

i = 2 → 0, ignore.

i = 3 → 3:

nums[1] = 3

[1,3,0,3,12]
pos = 2

i = 4 → 12:

nums[2] = 12

[1,3,12,3,12]
pos = 3

Now all non-zero elements are correctly packed at the front:

[1,3,12,_,_]

Fill from pos = 3 with zeros:

[1,3,12,0,0]
Why the relative order is preserved

We scan from left to right:

1 → 3 → 12

so we place them in exactly the same order.

Complexity
Time  = O(n)
Space = O(1)

The key pattern is:

i   = scanning pointer
pos = next position for a non-zero
