## Explanation

Why window size - maxFreq?

Take:

AABABBA

Suppose our window is:

AABA

Frequencies:

A → 3
B → 1

Window size = 4

Most frequent = 3

So we need:

4 - 3 = 1

replacement:

AABA
   ↓
AAAA

With k = 1, this window is valid.

Why shrink when this happens?
while((right - left + 1) - maxFreq > k)

This means:

We need more than k replacements, so the current window cannot work.

Therefore move left forward until it becomes valid again.

Mental model
Expand right
    ↓
Count characters
    ↓
Find most frequent
    ↓
replacements = window_size - maxFreq
    ↓
> k ? shrink from left
    ↓
valid ? update answer

The important formula to remember is:

replacements needed = window size - most frequent character count

Complexity:

Time  = O(n)
Space = O(1)   // only 26 letters
