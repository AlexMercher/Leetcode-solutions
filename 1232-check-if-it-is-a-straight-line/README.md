## Explanation

The first two points establish a direction:
(dx, dy)


Every other point must point in that same direction from the first point. The equation checks that the two direction vectors are proportional, without using division.
Complexity:O(n) time and O(1) extra space.
The pattern to remember: when checking whether points are collinear, use cross multiplication instead of comparing slopes.
