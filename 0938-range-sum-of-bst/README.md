## Explanation

Why these three cases work
root->val > high

Since this is a BST, everything in the right subtree is even larger.

So:

right subtree → definitely too large

Only search left:

return rangeSumBST(root->left, low, high);
root->val < low

Everything in the left subtree is even smaller.

So:

left subtree → definitely too small

Only search right:

return rangeSumBST(root->right, low, high);
low <= root->val <= high

The current node contributes.

But both subtrees can contain valid values, so search both:

return root->val
     + rangeSumBST(root->left, low, high)
     + rangeSumBST(root->right, low, high);

For your example:

10 → include
5  → too small → go right → 7
7  → include
6  → include
15 → too large → go left → 13 → too large

So:

10 + 7 + 6 = 23

## My Notes

The key mistake was: when the current node is inside the range, you must recurse into both sides instead of stopping at the current node.
