## Explanation

See push(1), push(2), push(3)

After push(1):

s1: [1] ← top

After push(2):

move 1 → s2

s2: [1]
s1: []

push 2

s2: [1,2]

move back

s1: [2,1] ← top 1

After push(3):

move:
s1 → s2

s2: [1,2] ← top 2
s1: []

push 3

s2: [1,2,3]

move back:

s1: [3,2,1] ← top 1

Now:

pop() → 1
pop() → 2
pop() → 3

Exactly a queue.

The key mistake in your version

You were doing:

old elements + new element
        ↓
      swap

but the transfer between stacks reverses the old elements.

You need the new element to end up underneath all the old elements, so the old front remains at the top.

That's why the correct version has two transfer loops, not one.
