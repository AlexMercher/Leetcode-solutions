## Explanation

The cleanest state is:

dp[i][j] = whether the first i characters of s1
           and the first j characters of s2
           can form the first i+j characters of s3

Before doing anything else, check:

if (s1.size() + s2.size() != s3.size())
    return false;

Because an interleaving must use every character of both strings exactly once.

Transition

At state (i, j), the next character of s3 is:

s3[i + j]

We have at most two choices.

Take from s1

If:

s1[i] == s3[i + j]

then we can consume one character from s1:

dp[i + 1][j]
Take from s2

If:

s2[j] == s3[i + j]

then we can consume one character from s2:

dp[i][j + 1]

Therefore:

dp[i][j] =
    (s1[i] == s3[i+j] && dp[i+1][j])
 ||
    (s2[j] == s3[i+j] && dp[i][j+1]);
Base case

When both strings have been completely consumed:

i == s1.size()
j == s2.size()

we have successfully formed all of s3:

dp[m][n] = true;
