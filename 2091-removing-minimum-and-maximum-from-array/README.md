## Explanation

Keep a track of minimum and maximum element in the running array then ensure that we get them in a ascending order so that we can make sure that our logic of extracting the number of elements from both ends or any of the one end can be implimented easily. 
if(minIdx>maxIdx) swap(minIdx,maxIdx);

int front=maxIdx+1;
int back=n-minIdx;
int bothends=minIdx+1+(n-maxIdx);
return min({front,back,bothends});
