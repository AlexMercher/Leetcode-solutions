## Explanation

When the question says:

"For every element, find the first greater element to its right."

think:

Monotonic decreasing stack

And the mental rule is:

A new bigger element resolves all smaller unresolved elements on top of the stack.

For:

1  3  4  2

you can visualize:

1
↓ 3 arrives → 1's answer = 3

3
↓ 4 arrives → 3's answer = 4

4
↓ 2 arrives → 2 is too small
