## Explanation

# Stone Game VIII — Explanation

Use prefix sums + game DP.

Let:

```cpp
prefix[i] = sum of stones[0 ... i-1]
After a move that consumes the first j stones, Alice/Bob gains prefix[j], and the game continues from state j.

Define:

dp[i] = best score difference the current player can obtain
        when the game is at state i

For a possible next state j:

dp[i] = max(prefix[j] - dp[j])

because the current player gains prefix[j], while the opponent gets the advantage represented by dp[j].

The naive recurrence checks every j, giving O(n²).

Notice that we repeatedly need:

max(prefix[j] - dp[j])

over a suffix. Maintain this maximum while traversing backwards.

Initialize:

best = prefix[n]

since dp[n] = 0.

For i = n-1 ... 2:

dp[i] = best;
best = max(best, prefix[i] - dp[i]);

Finally, best is the answer for Alice's first move.

Time: O(n)
Space: O(n)

# Mistakes

1. The backward loop must use `i--`, not `i++`.
2. State `dp[i]` represents the current player's best score difference.
3. The score gained by a move is a prefix sum.
4. The recurrence subtracts `dp[j]` because the opponent becomes the current player.
5. `best` stores the suffix maximum `max(prefix[j] - dp[j])`.
6. Use `long long` because prefix sums can exceed `int`.
