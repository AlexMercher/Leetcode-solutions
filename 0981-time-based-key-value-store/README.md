## Explanation

Suppose:

timestamps = [1, 4, 7, 10]
target = 8

If mid points to 7:

7 <= 8

7 is valid, but maybe 10 is too large while there could be another valid timestamp between them.

So:

left = mid + 1;

means:

"This works; now search for an even later timestamp that also works."

At the end, ans holds the value corresponding to the rightmost timestamp satisfying timestamp <= target.
Find largest timestamp <= target

That distinction is the entire issue.
