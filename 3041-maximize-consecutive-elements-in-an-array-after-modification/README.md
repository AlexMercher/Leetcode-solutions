## Explanation

For every original element x, we have two choices:

Choice 1: Don't increment it.

We use the value x.

To extend a consecutive sequence, the previous value must be x-1.

Therefore:
dp[x] = max(dp[x], dp[x-1] + 1);


Choice 2: Increment it by 1.

We use the value x+1.

To extend a consecutive sequence, the previous value must be x.

Therefore:
dp[x+1] = max(dp[x+1], dp[x] + 1);


There is one important detail here!

We must preserve the old value of dp[x] before updating it. Otherwise, we might accidentally use the same original element twice.
int prev = dp[x];

dp[x+1] = max(dp[x+1], prev + 1);
dp[x] = max(dp[x], dp[x-1] + 1);


This ensures that both choices use only previously processed elements.

If we have sorted the array then we don't need to use the max in the calculating of dp[x+1] rather we can just use that dp[x+1]=dp[x]+1;
dp[x]=dp[x-1]+1;
then do the max.

All smaller values are processed before larger values.

When processing num:

Choice 1: Increment the current element.
dp[num + 1] = dp[num] + 1;


We use the existing sequence ending at num and extend it by choosing the current element as num + 1.

Choice 2: Keep the current element unchanged.
dp[num] = dp[num - 1] + 1;


We extend the sequence ending at num - 1 using the current element as num.

Because of sorted processing, these assignments already maintain the best possible states. We don't need to compare against an older, better value.

Important: The order of these statements matters!
