## Explanation

# Isomorphic Strings — Explanation

Two strings are isomorphic if characters in `s` map to characters in `t` consistently and one-to-one.

We maintain two mappings:
- `sToT`: character from `s` → character in `t`
- `tToS`: character from `t` → character in `s`

For every position:
1. If neither character has a mapping, create both mappings.
2. Otherwise, verify both existing mappings match.
3. If either mapping conflicts, return `false`.

Two mappings are necessary because different characters cannot map to the same character.

Since the strings contain ASCII characters, arrays of size `256` are sufficient.

Time: `O(n)`
Space: `O(1)` (fixed 256-size arrays).

## My Notes

# Mistakes

1. Counting distinct characters is insufficient; isomorphism depends on positional mapping.
2. A one-way mapping allows two different `s` characters to map to the same `t` character.
3. `vector<int>(26)` is insufficient because the problem allows any ASCII character.
4. Use ASCII values directly as indices: `s[i]` and `t[i]`.
5. Always verify an existing mapping before accepting a character pair.
