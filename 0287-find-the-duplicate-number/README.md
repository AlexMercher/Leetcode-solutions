## Explanation

### Floyd's algorithm

Why does this return the duplicate?

Suppose:

0 → 1 → 3 → 2 → 4
              ↑   ↓
              └───┘

The cycle is:

2 → 4 → 2

The entry point is 2, which is exactly the duplicate value.

Pigeonhole proof

There are:

n + 1 numbers

but only:

n possible values: 1,2,...,n

If every number appeared at most once, we could have at most n numbers. Since we have n+1, at least one value must repeat.

And because the problem explicitly guarantees that only one value is repeated, that repeated value is uniquely determined.
