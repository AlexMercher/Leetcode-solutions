## Explanation

For Power of 4, you can build directly on the Power of 2 trick.

A number is a power of 4 if:

1, 4, 16, 64, 256, ...

Every power of 4 is also a power of 2, so first we need:

(n & (n - 1)) == 0

That checks that n has exactly one 1 bit.

But we need one more condition: that 1 bit must be at an even position when positions start from 0.

4  = 00000100
         ↑
       bit 2   ← even

16 = 00010000
        ↑
       bit 4   ← even

64 = 01000000
        ↑
       bit 6   ← even

A very neat trick is using:

0x55555555

In binary:

01010101010101010101010101010101

It has 1s exactly at bit positions:

0, 2, 4, 6, 8, ...

Why the second condition works

Take:

n = 16

16 = 0000000000010000
mask = 0101010101010101...

The 1 of 16 is at an even position, so:

n & mask != 0

But:

n = 8

8 = 0000000000001000

Its 1 is at bit position 3, which is odd.

Therefore:

8 & 0x55555555 = 0

so it is rejected.
