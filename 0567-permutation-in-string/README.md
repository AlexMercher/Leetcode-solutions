## Explanation

Dry run
s1 = "ab"
s2 = "eidbaooo"

Required:

a: 1
b: 1

Window size = 2.

Windows:

"ei" → e:1,i:1  ❌
"id" → i:1,d:1  ❌
"db" → d:1,b:1  ❌
"ba" → b:1,a:1  ✅

So return true.

Why fixed window?

A permutation of s1 must have exactly the same length as s1.

So if:

s1.length() = 3

we only care about:

s2[i ... i+2]

not arbitrary-length substrings.

The sliding operation

For every new character:

window[s2[i] - 'a']++;

When the window becomes too large:

window[s2[i-k] - 'a']--;

So we're always maintaining exactly k characters.
