## Explanation

# Unique BST — Catalan Number

The number of structurally unique Binary Search Trees (BSTs) with `n`
nodes is the `n`th Catalan number:

C(n) = 1 / (n + 1) * C(2n, n)

So instead of building every tree or using O(n²) DP, we can calculate
the Catalan number directly.

Understanding the Code
long long ans = 1;

for(int i = 1; i <= n; i++) {
    ans = ans * (n + i) / i;
}

return ans / (n + 1);

The loop calculates:

C(2n, n)

using the multiplicative form of the binomial coefficient.

Recall:

C(2n, n) = (2n)! / (n! * n!)

Instead of calculating factorials, calculate it incrementally:

i = 1:
ans = 1 * (n + 1) / 1

i = 2:
ans = previous * (n + 2) / 2

...

i = n:
ans = previous * (2n) / n

This produces:

C(2n, n)

Then Catalan requires division by n + 1:

Catalan(n) = C(2n,n) / (n+1)
Example: n = 3
ans = 1

i = 1:
ans = 1 * 4 / 1 = 4

i = 2:
ans = 4 * 5 / 2 = 10

i = 3:
ans = 10 * 6 / 3 = 20

So:

C(6,3) = 20

Finally:

20 / 4 = 5

Therefore:

Answer = 5
Why This Works for Unique BSTs

For every possible root:

left subtree  → smaller values
right subtree → larger values

If the root is chosen at position r:

left  = r - 1 nodes
right = n - r nodes

The number of trees is:

C(left) * C(right)

Summing over every possible root produces the Catalan recurrence:

C(n) = Σ C(i) * C(n-1-i)

which is exactly the Catalan sequence.

Complexity

Time: O(n)

Space: O(1)

long long is used for safe intermediate calculations.

## My Notes

1. Do not confuse `C(2n,n)` with the Catalan number; Catalan needs division by `n+1`.
2. The loop `ans = ans * (n+i) / i` calculates the binomial coefficient incrementally.
3. Use `long long` for intermediate values instead of `int`.
4. Do not use factorials directly; they grow extremely quickly.
5. Unique BST count is Catalan because every root splits the problem into independent left and right subtrees.
6. For n = 0, the Catalan value is 1, representing the empty tree.
