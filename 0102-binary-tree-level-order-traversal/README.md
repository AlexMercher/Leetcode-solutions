## Explanation

For:
        3
       / \
      9  20
         / \
        15  7

Initially:
q = [3]

size = 1
Process 3:
level = [3]
q = [9,20]

Add:
ans = [[3]]

Next:
q = [9,20]
size = 2

Process exactly 2 nodes:
9  → level = [9]
20 → level = [9,20]

While processing 20, its children are added:
q = [15,7]

Now:
ans = [[3],[9,20]]

Next:
q = [15,7]
size = 2

Process:
15
7

giving:
ans = [[3],[9,20],[15,7]]

The key idea is:
Queue gives BFS; size = q.size() tells us where one level ends.

Complexity:
Time:  O(n)
Space: O(n)
