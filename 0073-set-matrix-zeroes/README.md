## Explanation

Why we first store the positions

Suppose:

1 1 1
1 0 1
1 1 1

We first record:

pos = {(1,1)}

before changing anything.

Then zero row 1 and column 1:

1 0 1
0 0 0
1 0 1

If you started zeroing while scanning the matrix, the newly-created zeros would look like original zeros and could cause unnecessary propagation.

Complexity

With your approach:

Finding zeros:        O(m*n)
Zeroing each zero:    O(k*(m+n))

where k is the number of original zeros.

Worst case:

O(m*n*(m+n))

Space:

O(k)

There is an O(1) extra-space solution using the first row and first column as markers, but your pos approach is much easier to understand first.
