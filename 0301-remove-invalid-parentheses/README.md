## Explanation

Dry run: ()())()
First:
leftRemove  = 0
rightRemove = 1

The DFS must remove exactly one ).
It can remove the first possible offending choice:
(())()

or another:
()()()

Both use exactly one removal, so both are minimum.
The mental model
Think of DFS as:
At every character:

         keep
       /       
character
       \
        remove

But we restrict the branches:
remove '(' → only if leftRemove > 0

remove ')' → only if rightRemove > 0

keep ')'   → only if open > 0

finish     → leftRemove == 0
             rightRemove == 0
             open == 0

So the key pattern is:
First calculate exactly how much must be deleted → backtrack over where to delete it → never allow an invalid prefix → store unique valid results.

This is a classic "calculate required edits first, then backtrack over their positions" pattern.
