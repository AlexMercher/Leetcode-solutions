## Explanation

The problem is:

Put either + or - before every number so that the final sum is target.

We want to count the number of sign assignments.

1. First understand what + and - mean

Suppose we divide the numbers into two groups:

P = numbers given '+'
N = numbers given '-'

Then:

sum(P) - sum(N) = target

But we also know:

sum(P) + sum(N) = total

where:

total = sum(nums)

Add the two equations:

sum(P) - sum(N) + sum(P) + sum(N)
= target + total

2 * sum(P) = target + total

Therefore:

sum(P) = (target + total) / 2

So the original problem becomes:

Count the number of subsets whose sum is (target + total) / 2.

And that is a standard 0/1 subset-sum counting DP.

2. When is the answer automatically 0?

We calculate:

int required = (target + total) / 2;

But this only makes sense if:

Case 1: abs(target) > total

You cannot reach a value whose magnitude is greater than the sum of all numbers.

Example:

nums = [1,2,3]
total = 6

target = 10

Impossible.

Case 2: target + total is odd

We need:

2 * sum(P) = target + total

The left side is always even.

Therefore:

target + total

must also be even.

For example:

total = 5
target = 2

target + total = 7

Impossible.

So:

if (abs(target) > total || (target + total) % 2 != 0)
    return 0;
3. DP state

Let:

dp[j]

mean:

Number of ways to choose some of the numbers processed so far whose sum is exactly j.

Initially:

dp[0] = 1;

Why?

There is exactly one way to make sum 0:

choose nothing

Everything else starts at 0.

4. Processing each number

Suppose the current number is:

x

For every possible sum j >= x:

If there were:

dp[j-x]

ways to make j-x, then adding x gives:

dp[j-x]

new ways to make j.

So:

dp[j] += dp[j-x];

Because each number can be used once, we iterate j backwards.

for (int j = required; j >= x; j--)
