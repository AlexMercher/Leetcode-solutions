## Explanation

The three important lines
used[i] = 1;
curr.push_back(nums[i]);
backtrack(nums);

means:
Choose this element and explore all permutations that start with this choice.

Then:
curr.pop_back();
used[i] = 0;

means:
Undo that choice so another branch can use it.

Mental picture
                    []
          /          |          \
        [1]         [2]         [3]
       /   \        /  \        /   \
    [1,2] [1,3]  [2,1] [2,3] [3,1] [3,2]
      |      |      |      |      |      |
   [1,2,3] ...    ...    ...    ...    ...

Notice the key difference from combinations:
Combination: after choosing index i, continue from i+1.
Permutation: after choosing i, you can try every unused index again, because order matters.
So the pattern is:
Permutation = current vector + used[]

and when curr.size() == n, you've built one complete permutation.
