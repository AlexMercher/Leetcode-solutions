## Explanation

For:

s = "xyzzaz"

The length-3 windows are:

xyz
yzz
zza
zaz

Check each:

xyz → x,y,z all different → ans = 1
yzz → z,z repeated → no
zza → z,z repeated → no
zaz → z repeated → no

Final:

1
Complexity

There are n - 2 substrings, and each takes constant work: O(n) time

Space: O(1)

The recognition pattern here is simply:

Substring of exactly k characters → fixed-size sliding window.

Here k = 3, so we don't even need an actual window data structure.
