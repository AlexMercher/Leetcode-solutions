## Explanation

We need to find the number of inactive servers in the time range when the queries hit; range = [q-x,q].
Sort the logs as per the time which is logs[n][1] => time at which nth server was used.
Sort the queries as well so that the sliding window is easier to build.

Now we need to use the sliding window so that we can use them appropriately. The Right side grows till it is not equal to the Logs or time<=q. When the right grows we make sure that we update the count of the servers which went from idle to active.

Now the left size grows and first we update the server time and then we check if freq[server]==0 then it implies that we have an inactive server in the range [q-x,q] Thus we update the active count by -1; Now we use the number of inactive servers by updating the ans with n-active.
