## Explanation

For example:

x = 00101100
-x = 11010100   (two's complement)

x & -x
  00101100
& 11010100
-----------
  00000100

So it isolates the rightmost 1.

Now we categorize and do specific xor if that bit is present there if not then we just do xor with b and hence now we get a which is either the duplicate or the missing to confirm that we check if a is present in the given nums array or not if yes then we just return the {a,b} otherwise we return the {b,a};
