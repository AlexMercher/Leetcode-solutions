## Explanation

The key reason is that the state is not just the student's (row, col).

You also need to know:

which litter has already been collected
how much energy remains

So a state is:

(row, col, mask, energy)

where:

mask = which L cells have been collected

Since there are at most 10 litter cells:

2^10 = 1024

possible masks, which makes this manageable.

Why BFS?

Every move costs exactly 1.

So if we perform BFS from the starting state, the first time we reach a state where:

mask == (1 << litterCount) - 1

we have found the minimum number of moves.

This is essentially:

GRID
 ↓
GRAPH
 ↓
state = (position, collected-litter-mask, remaining-energy)
 ↓
all transitions cost 1
 ↓
BFS
Why greedy doesn't work

Suppose you see a nearby litter. Taking it immediately may be bad because:

near litter
   ↓
energy becomes low
   ↓
can't reach reset
   ↓
get stuck

A longer route to a reset area may be necessary before collecting another litter.

So there is no safe rule like:

"Always go to the nearest litter."

You need to consider multiple possible states.

Bitmask

Give every litter an ID:

L0 → bit 0
L1 → bit 1
L2 → bit 2
...

If you collect litter i:

mask |= (1 << i);

To check whether litter i is already collected:

if(mask & (1 << i))

All litter collected:

if(mask == (1 << L) - 1)
One subtle energy rule

After moving:

energy decreases by 1

Then, if the new cell is R:

energy = maximum energy

And a move is allowed when the current energy is at least 1.

If energy becomes 0 after a move, you can continue only if you landed on R, because otherwise you cannot make another move.

So this is a really nice BFS + bitmask state compression problem.

The state transition

From:

(r, c, mask, energyLeft)

move to a neighboring cell:

(nr, nc, newMask, newEnergy)

where:

newEnergy = energyLeft - 1

then:

land on L → set its bit
land on R → energy = full capacity
land on X → invalid
energy = 0 → cannot make another move

The bitmask is:

mask |= (1 << id);

and all litter collected is:

mask == (1 << L) - 1
Why the best array matters

Suppose we reach the same state:

(row=3, col=4, mask=10101)

once with energy 2, and later with energy 5.

The second state is strictly better:

same position
same litter collected
more energy

So there is no reason to process the weaker state.

This is essentially BFS + bitmask + resource dominance.

Complexity is approximately:

States ≤ m × n × 2^L
Transitions per state = 4

Time  = O(m × n × 2^L)
Space = O(m × n × 2^L)

With m,n <= 20 and L <= 10, the bitmask part is at most 1024, which is why the expanded state is feasible.
