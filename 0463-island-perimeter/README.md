## Explanation

Take:

0 1 0
1 1 1
0 1 0

Consider the center:

0 1 0
1 1 1
0 1 0

The center land cell has:

up    = 1 → no perimeter
down  = 1 → no perimeter
left  = 1 → no perimeter
right = 1 → no perimeter

So it contributes 0.

A corner land cell, say:

0 1 0

at the top:

up    → outside      +1
left  → water        +1
right → water        +1
down  → land         +0

So it contributes 3.

Another way to think about it

Every land cell starts with:

4 sides

Then every neighboring land cell removes one side from consideration.

So you can also calculate:

$$ \text{perimeter} = 4\times(\text{number of land cells}) - 2\times(\text{number of adjacent land pairs}) $$

Why 2?

Because for:

1 1

the shared edge belongs to both cells' side counts:

left cell  → 1 side removed
right cell → 1 side removed

So one shared edge reduces the total by 2.

Personally, for this problem I'd use the 4-neighbor check, because it directly matches the definition:

A perimeter edge is a side of a land cell whose neighboring cell is water or outside the grid.
