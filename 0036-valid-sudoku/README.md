### Mistakes(Very important that I remember how to access a given array boxes)
int box=(i/3) * 3 + (j/3);

For example, cell (4,7):

(4 / 3) * 3 + (7 / 3)
= 1 * 3 + 2
= 5

So (4,7) belongs to box 5.
